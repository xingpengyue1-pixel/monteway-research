# 首批5款标签与宣称红线卡

**版本**：V1｜**日期**：2026-10-28（Asia/Shanghai）｜**用途**：运营文案／客服话术／工厂标签设计／短视频口播**共用纪律卡**（可打印一至两页）  
**产品范围**：组合A 五款（拟议待审定）— **原味／可可／香草／咖啡／椰香**；形态独立条包约 30g；基粉拟议 **WPC80**；椰香＝WPC80＋真椰浆粉／椰奶粉  
**主路径**：特殊膳食用食品 · **运动营养食品 · 补充蛋白质类**（SC 常见 3003）；椰香款若脂肪等超 GB 24154 → **条件改**普通食品 · **固体饮料**（0606）  
**声明**：本稿为**内部纪律文件**，**不构成企业法律意见**；落地以现行国家标准、属地审查、承制许可、标签审图及法务／质量终审为准。营养数据、牌号、产地、纯度凡未核处**禁止写死数值**。  
**约束**：未改写 `01`／`02`／`03`；不替代 `09` 董事长勾选；依赖实测与企业输入（见 `04`／`10`）。

## 一、允许说（绿灯｜短列表）

在**最终产品性质书面定性为「运动营养食品 · 补充蛋白质类」**且标签／检测齐套的前提下，下列表述方向一般可用（具体措辞仍须法务／质量过审）：

| # | 允许方向 | 备注 |
|---|---|---|
| 1 | 「运动营养食品」「补充蛋白质类」（或标签法规要求的规范分类用语） | **仅当**最终定性为此；改走固体饮料后**不得**再作主展示面主称 |
| 2 | 蛋白质来源为**乳清蛋白浓缩粉／浓缩乳清蛋白**（WPC；工作称呼拟议 WPC80） | 须与配料表、COA 一致；**COA 待企业输入** |
| 3 | 独立条包、便携、单次定量、冲调饮用 | 体验与形态描述，不作疗效 |
| 4 | 口味名称：原味／可可／香草／咖啡／椰香 | 椰香须与「真粉入料」配料一致时方可强调「添加椰浆粉／椰奶粉」 |
| 5 | 成年人日常健身、运动后营养补充、运动人群蛋白补充等**场景** | **不做**增肌疗效、疾病康复、减脂治疗等承诺 |
| 6 | 标签已实测并核准的营养成分数值（每份／每 100g） | **实测后填**；本稿不写死克数 |
| 7 | 依法应标的贮藏、冲调方法、不适宜人群提示（如咖啡因相关） | 按实测与标准 |

> 女性便携等**同 SKU 场景分层**可谈便携／控量（对照 05），**不得**借机宣称 0 乳糖、祛痘、燃脂。

## 二、禁止说（红灯｜醒目）

**下列表述一律禁止**（含包装主展示面、配料旁注、电商详情、达人口播、客服话术、私域海报）：

| # | 禁止类型 | 示例／边界（非穷尽） |
|---|---|---|
| R1 | **疾病预防／治疗／诊疗营养** | 术后康复、临床营养、放化疗营养、替代药物、治愈、抗菌消炎等 |
| R2 | **保健功能／蓝帽话术** | 「增强免疫力」、展示蓝帽子标志、目录内功能声称（无备案／注册凭证时） |
| R3 | **特医／FSMP** | 「特医」「特殊医学用途」「请在医生或临床营养师指导下使用」等（无注册证时） |
| R4 | **未核原料身份** | WPI／分离乳清、Native、0 乳糖／无乳糖、水解／酶解小分子肽等（COA／实测未核前） |
| R5 | **疗效化／绝对化运动效果** | 「保证增肌」「必瘦」「抗肌少症」「逆转肌少」等疗效或绝对化承诺；普通／运动营养路径下的诊疗性抗肌少话术 |
| R6 | **椰子表述造假** | 仅用香精／「椰子味」却写「添加椰子粉／真椰奶／椰浆粉」；配料与卖点不一致 |
| R7 | **产地／有机／进口等未核宣称** | 虚假有机、未核进口产地、未核「澳洲奶源」等；无证书不写 |
| R8 | **儿童／特殊医学剂量指导** | 儿童剂量、医嘱替代、与药物相互作用指导等 |
| R9 | **类别混称** | 固体饮料包装主展示面标「运动营养食品」；或运动营养包装暗示保健／特医 |

**口播／客服一票否决**：出现 R1–R3、R6 任一即停用该脚本并交质量／法务。

## 三、分口味注意

| 口味 | 必须注意 | 禁止加戏 |
|---|---|---|
| **原味** | 作营养与感官基准；配料居首应为乳清蛋白浓缩粉（除非实测用量被辅料反超—应避免） | 勿暗示「更纯＝WPI」 |
| **可可** | 可可粉／风味合法依据；**交叉污染**与过敏原评估；苦涩／结团属体验描述边界 | 勿宣称「燃脂巧克力」等 |
| **香草** | 香精／香兰素限量合法；与原味区分度话术保持客观 | 勿虚构天然香草含量未核值 |
| **咖啡** | **咖啡因**含量披露与**不适宜人群**提示；勿与未核「生椰拿铁」复配名混称 | 勿暗示提神疗效或替代咖啡药品 |
| **椰香** | **乳过敏原必标**；椰子是否按「坚果」提示 **待法务确认**（倾向从严）；**真粉**表述须与配料表一致；脂肪闸门与是否改 0606 | 禁香精冒充加椰子粉；禁「无乳／纯植物」 |

## 四、标签要素检查表（勾选空表｜设计／审图用）

> 要点按 **GB 7718**、**GB 13432**（特殊膳食用食品标签）、**GB 24154**（运动营养食品通则）等**公开口径**罗列；**以现行国标文本与属地审图要求为准**。改走固体饮料时，运动营养专属项不适用，须改用普通食品标签路径。

| # | 要素 | 运动营养路径（主） | 若改固体饮料（椰香或全线备选） | 状态 |
|---|---|---|---|---|
| L1 | 食品名称与属性名（反映真实属性） | 须符合特膳／运动营养分类标示要求 | 按固体饮料属性命名；不得暗示特膳／保健 | □ |
| L2 | 配料表（用量降序；复合配料展开） | 乳清蛋白浓缩粉居首（原则）；辅料合法 | 同左；椰浆粉名称可识别 | □ |
| L3 | 营养成分表 | 按 GB 13432 等；**实测后填**；本稿不写死 | 按 GB 28050 等普通预包装营养标签规则 | □ |
| L4 | 致敏物质提示 | **乳**强制口径（GB 7718-2025 致敏物质标示趋严，实施过渡以国标为准，宜提前改版） | 同左；椰子是否纳入坚果 **待法务** | □ |

| L6 | 生产日期、保质期、批号 | 必备；椰香保质期不得照搬纯 WPC 未验证值 | 必备 | □ |
| L7 | 委托方／受托方名称、地址；产地 | 委托生产信息齐全 | 同左 | □ |
| L8 | 执行标准／产品标准代号 | 按企标或相应国标／行标 | 常见参照固体饮料相关标准等 | □ |

## 五、渠道话术示范

### 5.1 安全向（可用方向｜仍须过审）

1. 「这是面向成年人的**运动营养**蛋白补充条包，日常健身后冲调方便，口味有原味／可可／香草／咖啡／椰香可选。」  
2. 「配料以**浓缩乳清蛋白**为主；椰香款添加的是**食品级椰浆粉**（以标签配料表为准），不是只加香味。」  
3. 「每份蛋白克数以**包装营养成分表实测标注**为准；请按标签冲调与贮藏。」

### 5.2 禁止示范（对照｜出现即停）

1. 「术后恢复、抗肌少症、增强免疫，跟特医粉一样，还能当蓝帽子保健品用。」  
2. 「我们这是 WPI 分离乳清，零乳糖，吃了稳增肌不长胖。」  
3. 「椰香就是生椰拿铁配方，加了真椰奶，无过敏原，儿童老人都能当药补。」

## 六、底部纪律（必读）

1. **依赖**：`09` 董事长勾选（五款名单、椰香改类、不做蓝帽／FSMP 等）与营养／咖啡因／脂肪等**实测**；COA 与法务过敏原终裁见 `04`／`10`。  
2. **改类规则**：椰香（或全线）改走**固体饮料**后，主展示面与广告**不得再标「运动营养食品」**及特膳分类用语；话术同步降级为普通冲饮粉／固体饮料口径。  
3. **终审**：正式上架包装、电商主图文案、达人脚本发布前，须经**质量＋法务**终审；本红线卡不能替代审图意见。  
4. **本卡不构成法律意见**；与 `08` 资质周期、`10` 询价红线一并使用。
