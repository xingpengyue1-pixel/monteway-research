## 1. 一句话结论

**五款建议统一主走「特殊膳食用食品 · 运动营养食品 · 补充蛋白质类」（生产许可目录常见类别 3003「其他特殊膳食食品·运动营养补充品」），产品形式全部为独立条包（约 30g 粉剂）冲调粉；椰香款因椰浆粉脂肪升高，须在打样后单独核 GB 24154 脂肪≤6g/100g 等指标——若超标则该款改走「普通食品 · 固体饮料（蛋白固体饮料）」或其他普通食品路径，其余四款仍优先保持运动营养主路径一致。蓝帽与 FSMP 仅作对照，不推荐首批。总预期周期（资料齐套后到可合法生产销售的粗区间）：委托＋承制方已具备对应 SC 时约 **2–4 个月**（打样／检验／合同与委托报告／首批放行并行）；若需新建／变更「运动营养」生产许可或椰子款改类，常见拉长至约 **4–8 个月**（含试制检验与整改，法定许可钟约受理后 10＋5 工作日＋现场核查 5 工作日，实务远长于法定钟）。**

| 维度 | 结论 |
|---|---|
| 主推荐产品性质 | **特殊膳食用食品 · 运动营养 · 补充蛋白质类**（五款统一） |
| 椰子款额外门槛 | 脂肪／蛋白稀释／过敏原／稳定性；**超标则改固体饮料等** |
| 不推荐首批 | FSMP 国家注册；蓝帽（除非企业本轮书面定性某款为保健品） |
| 周期量级（齐套后） | **约 2–4 月**（委托＋已有 SC）；**约 4–8 月**（新建／变更特膳许可或改类） |

### 2.1 总表阅读说明

- **五款默认同一主路径**：降低「一款特膳、一款固体饮料、一款蓝帽」的许可与话术分裂成本。  
- **椰子款是唯一可能迫使「性质分叉」的 SKU**：GB 24154 补充蛋白质类公开口径常见要求包括蛋白质 ≥50g/100g、优质蛋白占比 ≥50%、脂肪 ≤6g/100g 等（以现行国标文本为准，**成品实测后终裁**）。  
- **分装红线**：多省运动营养审查细则／方案明确 **不得以分装方式生产**，须完成整个生产工艺；条包形态允许，但工艺须是「混配灌装」等完整流程，而非仅拆大包。来源见 Sources 中食安信梳理、地方细则公开页。

## 3. 分性质对照章

### 3.1 特殊膳食用食品 · 运动营养食品（补充蛋白质类）— **主推荐**

| 项 | 公开摘要（非法律意见） |
|---|---|
| **定位** | 属「特殊膳食用食品」标准体系（GB 13432、GB 24154），**不是**《食品安全法》三类「特殊食品」（保健食品／FSMP／婴配）的国家注册体系 |
| **生产许可** | 目录：**3003 其他特殊膳食食品**，品种明细含「运动营养补充品」等（市场监管总局 2020 年第 8 号《食品生产许可分类目录》） |
| **审查依据** | 国家层面尚无统一「运动营养食品生产许可审查细则」时，主要依 **各省审查细则／方案**＋GB 24154；仅在本行政区域有效 |
| **形态与工艺** | 允许固体／液态／半固态等（以地方细则为准）；**禁止胶囊、口服液、丸剂等剂型**（多省细则口径）；**不得分装** |
| **关键指标（粉状补充蛋白质类，公开口径）** | 蛋白质 ≥50g/100g；优质蛋白占比 ≥50%；脂肪 ≤6g/100g 等——**以 GB 24154 现行文本与成品实测为准** |
| **标签** | GB 13432＋GB 24154＋GB 7718／营养标签等；主要展示面标「运动营养食品」及分类；**不得做保健功能声称、不得疾病预防／治疗** |
| **申请／变更材料（生产许可，通则口径）** | 申请书、主体资格、食品类别与品种明细、设备布局／工艺流程、主要设备设施清单、食品安全管理制度、试制食品检验报告、标签样稿等；属地清单以当地告知为准 |
| **法定审查钟（《食品生产许可管理办法》总局令第 24 号）** | 材料补正告知 ≤5 工作日；现场核查自接受任务起 **5 工作日**内完成；除当场决定外，自受理起 **10 工作日**作出决定，可延长 **5 工作日**；准予后 **5 工作日**发证。**实务周期**含厂房整改、试制检验排队、补正，常远长于法定钟 |
| **对五款适用性** | **①–④ 高度适配**（轻调味、脂肪风险低）；**⑤ 条件适配**——脂肪达标则同路径，超标则退出本路径 |

### 3.2 普通食品 · 固体饮料（含蛋白固体饮料）— **备选／椰子款分支**

| 项 | 公开摘要 |
|---|---|
| **定位** | 普通食品；许可目录 **0606 固体饮料**，品种明细含风味固体饮料、**蛋白固体饮料**、果蔬／茶／咖啡／可可粉固体饮料、其他固体饮料等 |
| **执行标准／标签** | 常见参照 GB／T 29602《固体饮料》等＋GB 7718、GB 28050；**不得**按运动营养／特膳主展示面宣称；**不得**暗示保健功能；「蛋白粉」等名称与高蛋白声称须符合属性与营养标签规则，避免「糖粉冒充蛋白」质疑 |
| **准入** | 承制方 SC 品种明细覆盖对应固体饮料；委托方经营／备案资质符合委托生产办法 |
| **材料与流程** | 与普通食品生产许可／委托类似：配方、工艺、试制检验、标签、合同与委托报告；**无**运动营养特膳地方细则中的「不得分装」等特膳专属要求（仍须符合普通食品生产规范） |
| **周期** | 承制已有 0606 明细时，与食品委托放行接近，粗估 **约 1.5–3 月**（齐套后）；新建／变更明细同许可法定钟＋实务整改 |
| **对五款适用性** | 可作 **全线备选**（若企业放弃运动营养叙事）；**⑤ 的明确分支**（运动营养脂肪等超标时）；①–④ 改走固体饮料会削弱「运动营养」货架与话术一致性，**不优先** |

### 3.3 保健食品（蓝帽）— **对照；不推荐首批**

| 项 | 公开摘要 |
|---|---|
| **定位** | 《食品安全法》特殊食品；须注册或备案；标签蓝帽子标志；功能声称仅限允许目录 |
| **乳清蛋白路径** | 《保健食品原料目录 乳清蛋白》发布后，符合目录技术要求的国产产品可走 **备案**（常见功能口径「有助于增强免疫力」等）；配方配伍、每日蛋白质用量范围（公开解读：**6–25g／日**）、剂型与辅料须符合《保健食品原料 大豆分离蛋白 乳清蛋白备案产品剂型及技术要求》等；不符合目录的配伍／功能走 **注册** |
| **备案人资质** | 国产备案人应为保健食品生产企业（或法规允许的原注册人等）；进口另有规定 |
| **关键材料（备案口径）** | 备案登记表与承诺、主体证明、配方、工艺、产品技术要求、三批中试以上功效／标志性成分·卫生学·稳定性、三批全项目检验、包材、标签说明书样稿、原料全项目检验（目录解读：报告提交备案时有效期约 2 年）等 |
| **周期量级** | 材料符合要求时监管部门可「当场备案」；**实务总周期**主要卡在中试、三批检验与资料——行业公开服务口径常见国产约 **5–6 个月**量级（非法定上限）。注册路径审评法定常见 **60 工作日**量级＋核查／复核检验另计，总长常以 **年** 计 |
| **对五款适用性** | **不推荐首批并行**：需保健食品生产许可＋蓝帽凭证；「增强免疫」≠运动营养／术后／抗肌少；与当前「来料条包验证」能力与周期不匹配。仅当企业本轮书面把某款定性为保健品时另立路径 |

### 3.4 特殊医学用途配方食品（FSMP）— **为何不适合首批（简要对比）**

| 项 | 公开摘要 |
|---|---|
| **定位** | 特殊食品；国家市场监督管理总局 **注册**（《特殊医学用途配方食品注册管理办法》，总局令第 85 号，2024-01-01 施行） |
| **申请人能力** | 须具备相应研发、生产、检验能力；提交研发报告、配方依据、工艺、标准、标签说明书、检验、能力证明及营养充足性／特殊医学用途临床效果等材料；特定全营养一般还须临床试验 |
| **审评钟** | 自受理起审评 **60 工作日**（可延长 30）；补正、现场核查、抽样检验等时间 **不计入**审评时限——实务从立项到获批常见 **一年以上**（视临床试验与否） |
| **许可目录** | 2801／2802 等，且须载明注册批准文号 |
| **对五款适用性** | **不适合首批 5 款**：周期与能力远超「拟议 WPC80 来料开发条包」；普通／运动营养标签亦不得冒用特医用语。术后／疾病营养场景应永久与本品话术隔离（对照 05） |

|---|---|---|---|---|

| ⑤ 椰香 | **椰浆粉／椰奶粉规格书**（脂肪％、载体、是否含酪蛋白酸钠、微生物／农残）；添加比例试算与成品**脂肪／蛋白**实测（对标 GB 24154）；单独稳定性／氧化方案；过敏原提示文案（乳＋椰子是否按坚果**待法务**）；若改固体饮料——另附 0606 路径标签与执行标准说明 |

### 4.3 型式检验／出厂检验提示

- 首次许可或增加食品类别变更：现场核查常核验 **试制食品检验报告**（可自检或委托有资质机构）。  
- 上市后按产品标准与属地监督抽检要求做出厂／留样。  
- **五口味**：至少对基准配方（建议原味）做完整型式；其余口味做配方差异相关项目＋全项营养标签值确认——具体项目以承制质检与标准文本为准（**待核**）。

## 5. 分阶段节奏建议（五款并行 · 甘特式文字）

> 假设：企业确认组合A；主路径运动营养；委托生产；检索日为起点的「工作周」粗排。**最长路径项加粗。**

| 阶段 | 约略时段 | 并行动作 | 卡点／最长路径 |
|---|---|---|---|
| **S0 决策锁定** | 第 0–1 周 | 书面确认五款名单；类别主路径；椰子粉「真粉」原则；现金／MOQ（5 齐灌 vs 3＋2 分期） | 无企业书面终裁则后续全停 |
| **S1 询价与承制筛选** | 第 1–4 周 | 同时询：①SC 明细（3003／0606）；②是否接受来料；③五口味打样与卷膜 MOQ；④能否完整工艺（非分装） | **最长：找到具备 3003 的承制方** |
| **S2 打样与指标闸门** | 第 3–8 周（与 S1 重叠） | ①–④ 轻调味打样；**⑤ 优先测脂肪／蛋白**；感官与冲调 | **最长：⑤ 脂肪是否过 GB 24154**→决定是否改类 |
| **S3 检验与标准文件** | 第 6–12 周 | 试制检验、营养标签值、标签审图（含过敏原）、企标／执行标准定稿 | 检验排队与整改 |
| **S4 许可／委托合规** | 第 8–16 周 | 已有 SC：签合同＋**10 工作日内委托报告**＋标签定稿；无 SC／须变更：**生产许可申请＋现场核查＋试制报告** | **最长路径：新建／变更 3003 许可（实务常拖到阶段末期）**；或⑤ 改 0606 的明细变更 |
| **S5 首批灌装与上市** | 许可／报告就绪后 2–6 周 | 包材到料、灌装、出厂检验、放行、渠道上架；建议「3＋2」分期缓释现金 | 包材五版起印与原料吨配额 |

**并行要点**：S1–S3 可重叠；**不要**等五款全部感官完美再启动承制 SC 核验。  
**关键路径（Critical path）**：承制 **3003 资质确认** → **⑤ 脂肪闸门** → **试制检验齐套** → **许可变更或委托报告完成** → 首批放行。  
**若⑤ 改固体饮料**：①–④ 仍走特膳时，出现「双路径」标签与合同——须在 S2 闸门后立刻分叉管理，避免五款混用主展示面用语。
