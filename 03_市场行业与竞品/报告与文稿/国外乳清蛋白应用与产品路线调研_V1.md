## 1. 一句话结论

**国外主流路线**是「**WPC 入门／性价比冲饮粉（罐装＋样品条）→ WPI／水解高端粉与透明蛋白水 → RTD 即饮／蛋白棒零食化 → 临床／减重／老年另立 medical food 或医院渠道料线**」；口味上以经典巧克力／香草／草莓为底座，用**咖啡厅联名、糖果联名、季节限定、真椰／椰子系**做差异化。对蒙特威：**首批最可直接借鉴的是「WPC80＋独立条包／stick 矩阵＋运动营养定位＋椰香真粉差异化」**；罐装粉、蛋白棒、RTD、透明蛋白水、植物复配、特医／老年医疗渠道均属**二期或明确不照搬**（与 `05`–`09` 一致）。

## 3. 产品路线图（可分期）

```
海外常见演进（公开观察）
  ┌─① 粉剂核心：WPC 罐装／袋装（ON／MyProtein 等）
  │     └─ 样品／旅行 stick／sachet（ON Samples；UNJURY／CSE 等次抛）
  ├─② 便利形态：同配方口味矩阵＋订阅／多样包

  └─④ 特医／老年／减重医疗渠道：WPI 次抛＋医院推荐叙事（UNJURY 等）——与普通运动营养分账

蒙特威建议分期（对照 05–11｜拟议）
  P0 首批：拟议 WPC80 ≈30g 独立条包 × 约5口味（含椰香真粉）｜运动营养主路径

```

## 7. 对蒙特威：可借鉴／二期／明确不照搬

### 7.1 可借鉴（服务首批拟议 ≈5 款 WPC80 条包）

1. **形态**：海外「single-serve stick／sachet」已成成熟货架语言——对齐拟议 30g 独立条包。  
2. **场景话术边界**：运动营养补充蛋白／训练后恢复（对齐中国「运动营养食品·补充蛋白质类」候选路径），**不**借海外 medical／bariatric 话术。  
3. **口味矩阵**：经典三件套＋咖啡＋**椰香真粉**差异化（海外有咖啡厅化与椰子口味先例）。  
4. **原料诚实分层**：公开教育 WPC vs WPI（Glanbia／澳站）——对客可讲「浓缩乳清入门／口感」，**不**把 WPC80 说成 isolate／0 乳糖。  
5. **样品逻辑**：大牌用 sample packets 获客——首批条包本身即可兼样品与零售。

### 7.2 二期候选（不进首批并行可售）

| 候选 | 理由 | 海外锚点 |
|---|---|---|
| 罐装／家庭装 | 新包材 MOQ | ON 大罐 |
| 订阅／多口味盒 | 运营与库存复杂 | MyProtein 口味墙 |
| 蛋白棒／曲奇 | 质构与承制另线 | Quest |
| 同料轻克重条 | 易被当成第二 SKU | UNJURY 10.5g 是 **WPI** 临床向，不可简单对标克重 |
| A 线卖粉给酸奶／烘焙厂 | 原料应用 | Glanbia／NZMP 应用叙事 |

### 7.3 明确不照搬（对照 `05`–`11`）

| 海外常见项 | 不照搬原因 |
|---|---|
| UNJURY 式 medical／医院推荐／术后减重叙事 | 中国 FSMP／诊疗暗示红线；首批不做特医 |
| WPI 另立女性／0 乳糖次抛 | 须另料＋乳糖实测；`09` 明确不做 |
| 透明蛋白水／Isopure Clear | 通常需 WPI；现有 WPC80 不宜硬做 |
| Premier 级 RTD 矩阵 | 需液态产线与热稳牌号 |
| 蓝帽「增强免疫」或酶解＋CaHMB 抗肌少 | 另立许可／配方；`09` 否决首批 |
| 婴配 | 边界外，不做 |

### 7.4 定位与宣称路径对照（不可照搬中国）

| 海外公开口径 | 大致含义 | 中国对照（仅提示） |
|---|---|---|
| **Sports nutrition／dietary supplement** | 美：常 Supplement Facts；训练恢复结构功能声称受限 | 更近：**运动营养食品（特膳）** 或普通食品固体饮料；**≠**保健食品蓝帽 |
| **Conventional food／RTD／bar** | Nutrition Facts；便利高蛋白食品 | 普通食品／饮料；不得疾病声称 |
| **Medical food** | 医嘱下膳食管理特定疾病；与补剂分轨 | 近 **FSMP**；注册门槛高——**首批不做** |
