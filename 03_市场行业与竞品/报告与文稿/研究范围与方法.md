# 研究范围与方法

研究日：2026年11月8日；用户选择：原料B2B与自有品牌并行，判断先后顺序。

覆盖八个方向：统计边界、全球供需、价格周期、区域贸易、供应商及扩产、消费产品与应用、中国替代与竞争、蒙特威进入路径。

工具：优先检查用户指定的Bright Data。CLI config可读取；budget和zones均返回Network request failed，未改变账号、网络和全局配置。改用联网搜索和网页/PDF原文读取。没有将内部文件上传至公开检索服务。

证据优先级：政府/统计和监管原文、上市公司披露、行业协会、供应商官方资料、商业研究摘要。市场规模只采用公开摘要，未购买报告。供应商材料用于确认其公开产品/投资/合作动作，不用于证明营养优越性。

本轮本机尝试归档USDA、USDEC PDF均遇SSL连接失败，详见download_log.json；网页工具能取得PDF文本。没有声称保存了原PDF或完成视觉验收。USDEC同一动态链接曾返回7月、8月两种解析快照，正文主要以11月5日USDEC文章及11月2—6日USDA周报确认价格方向，不以冲突版本建立全球总量模型。

未实施：付费报告购买、供应商/客户联系、询价、样品测试、企业许可与批次放行、平台销售后台审计。研究建议不等于这些工作已经完成。
