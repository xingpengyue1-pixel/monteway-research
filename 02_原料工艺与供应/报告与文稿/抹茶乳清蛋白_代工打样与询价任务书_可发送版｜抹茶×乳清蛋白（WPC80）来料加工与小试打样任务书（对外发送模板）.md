## 一、 致候选合作工厂的研发打样与询价函正文

**主题：关于【客供WPC80＋千目抹茶粉】30g条包系列新品（0606固体饮料／3003运动营养）小试打样与来料代工询价函**

尊敬的合作伙伴项目负责人：

我方现持有批次稳定的进口速溶浓缩乳清蛋白粉（**WPC80**，首批计划投料规模为 **1,000 kg**），拟委托贵司开展**“抹茶×乳清蛋白”系列30g独立条包产品**的配方打样、中试及来料委托生产。

本次开发共规划三个细分产品方向（贵司可按具备的SC许可明细承接其中1—3款）：
1. **方向A（0606 蛋白固体饮料）**：**生打椰椰抹茶乳清蛋白饮**（核心结构：我方客供WPC80 72% + 国标一级千目抹茶粉 5.5% + 纯椰乳粉 16% + 赤藓糖醇/胶体/甜味剂）；
2. **方向B（3003 运动营养食品—补充蛋白质类）**：**千目浓抹高蛋白乳清粉**（核心结构：我方客供WPC80 89.5% + 国标一级千目抹茶粉 6.5% + 脱脂乳粉/赤藓糖醇/甜味剂；要求成品蛋白质≥68g/100g，脂肪严控在GB 24154规定的≤6.0g/100g以内；另请同步评估复配18.5% WPI90使成品蛋白质≥75g/100g的B3备选方案）；
3. **方向C（3003 运动营养食品—控制能量类·部分代餐）**：**抹茶高纤轻控能部分代餐粉**（核心结构：我方客供WPC80 48% + 千目抹茶粉 5.5% + 菊粉 14% + 圆苞车前子壳粉 4% + 熟化燕麦粉/异麦芽酮糖 18% + 纯椰乳粉 8% + GB 24154控能类复合维矿预混料；按每餐2袋60g满足835—1670kJ能量、蛋白供能比25%—50%、脂肪供能比≤25%要求）。

请贵司在收到本函后，就以下事项予以书面确认并安排首轮实验室小样（每梯度500g—1,000g）：

1. **资质与承接确认**：请提供实际承制法人的营业执照及《食品生产许可证》（SC）正副本与品种明细（确认是否同时覆盖 **0606蛋白固体饮料** 与 **3003运动营养食品-补充蛋白质类/控制能量类**），并明确是否接受我方客供WPC80原料（以及是否接受客供或指定品牌抹茶粉）。
2. **抹茶粉原料准入确认**：本项目严禁使用普通炒青绿茶粉或添加铜叶绿素钠调色。请确认贵司现有合格供应商库中是否有符合 **GB/T 34778—2017《抹茶》一级标准**（粒径 $D_{60}\le 15\ \mu\text{m}$ 即≥1000目、叶绿素≥0.55%、L-茶氨酸≥1.2%、茶多酚11%—15%、水分≤5.5%、符合 **2026年3月1日实施的新版GB 2763—2026农残标准** 及冷冲即食低微生物级 **菌落总数≤1,000 CFU/g**）的纯正遮光蒸青抹茶粉（如浙江径山抹茶或贵州铜仁欧标抹茶），并提供原料规格书（COA）及含税单价。
3. **车间工艺与包材锁鲜控制**：鉴于抹茶叶绿素极易受光氧脱镁褐变且超微粉易静电抱团，请确认贵司能否执行：（a）**三级等量递增预混工艺**（先将抹茶粉与结晶赤藓糖醇/二氧化硅干法预混打散静电，最后与速溶WPC80低速总混以保护卵磷脂造粒层）；（b）30g条包采用**PET/AL/PE纯铝箔四层/三层高阻隔复合膜**并配套**充氮包装（残氧量≤3%—5%）**。
4. **分项透明报价与1吨拆单MOQ**：若我方首批1,000kg WPC80按单一SKU投产，或按 **“方向A 400kg + 方向B 400kg + 方向C 200kg”**（单SKU总混料量均在416kg—555kg之间）拆单投产，请分别报出单SKU最低混合量（MOQ）、每条加工费、辅料明细单价、铝箔卷膜与10条装彩盒起订量及单价、打样与出厂检验费用、综合净得率承诺及全流程交期。
