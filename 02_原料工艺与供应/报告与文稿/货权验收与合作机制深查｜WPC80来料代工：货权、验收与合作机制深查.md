# WPC80来料代工：货权、验收与合作机制深查

2026年10月28日｜第四轮专题研究｜WPC80、1吨原料、30g条包

本轮继续沿用「1吨指我方提供的原料」这一研究口径。没有取得本单报价、真实COA、正式配方或合同。本轮新增价值是明确交易结构、证据要求和退出成本；前轮的企业候选与历史费用信息不重复罗列。

**建议把首批定义为一项分阶段验证的委托生产项目。** 先解决谁签约、谁制造、用什么标准验收及何时可以停止，再锁定整批原料和印膜。这里的分阶段授权不等于已经决定分批生产，也不假设工厂接受小批量。

## 一、这轮补到了哪些会改变决策的细节

| 新增认识 | 对原计划的具体修正 | 当前证据状态 |
|---|---|---|
| 所有权与实际取回能力是两件事 | 货权条款还要配合留置约定、费用结算、库存特定化和退出程序 | 民法典及破产法官方文本；具体合同待审 |
| 「集团接单、另一工厂制造」可能构成多重委托 | 核准每一法律主体的角色，不只拿最后一家工厂的SC证 | 总局2026年实施问答；相关办法12月1日起施行 |
| 保健食品备案路线有委托生产限制 | 不把「乳清蛋白可以用于备案产品」直接理解为我方可自由贴牌 | 同一官方问答第26问，需结合实际产品身份 |
| 蛋白质结果存在计算口径差异 | 在检验委托单中记录基准、方法、换算系数和样品配方 | ADPI技术标准；国内最终适用方法需实验室确认 |
| 送检合格不自动代表整批合格 | 将抽样过程与报告同时作为验收证据 | 检验检测机构监督管理办法第9条 |
| 监管复检与商业复核不能混用 | 质量争议条款不能写成任何不合格都重检至合格 | 2025年修正的食品安全抽样检验管理办法 |
| 首批费用中的一部分是不可撤回投入 | 把退出时点、剩余膜和不可取消采购额纳入比价 | 本轮商业分析，实际金额待回件 |

## 二、合同主体要沿着生产链核对

前轮已提示核实际工厂。本轮进一步查到总局实施问答第4问的多重委托情形：A委托B，B再委托C，B作为受托方仍须具备相应生产许可和能力；A、B、C的监督责任及预包装标签标注应沿链条安排。该解释对应的办法自2026年12月1日起施行，截至本报告日期尚未实施。[官方实施问答](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/spscs/art/2026/art_2c532fed8fd94e179d83bd7a9c2ee461.html)

**商业含义：** 品牌名、集团名、销售公司的抬头与生产法人的关系必须明确。不能仅凭销售人员展示某工厂许可证，就认定签约公司可合法承担全部受托角色。也不能把经纪服务、销售代理与多重生产委托混成一种关系。

| 可讨论结构 | 应画清的关系 | 重点核对 |
|---|---|---|
| 我方直接委托实际工厂 | 原料、加工任务、成品交付均直接对应 | 工厂签约、收款、制造及报告主体能否对应 |
| 服务公司提供研发或协调服务，我方另与工厂签生产合同 | 服务合同与生产合同各自交付物明确 | 服务方是否实际控制配方／订单而构成另一法律关系，不能只按合同名称判断 |
| 我方委托B，B再交C制造 | 多重委托链条 | B与C的资格、责任、监督、标签及报告安排 |
| 我方只出售原料给品牌或制造商 | 原料买卖，成品由买方负责其业务 | 不再自动享有成品货权或终端利润；原料供应责任仍存在 |

本轮对衡美／吉美、天益／天利、西子相关主体均不预设上述哪一种结构。下一轮回件应增加一张「合同、付款、收料、制造、检验、发货、开票主体图」。名称不一致并不当然违法，但需要真实、可解释的法律和业务依据。

## 三、保健食品备案不能被当作快捷贴牌路径

总局实施问答第26问明确区分注册与备案保健食品的委托生产安排，并指出备案保健食品原则上不得委托生产，原注册人对转备案产品有相应例外。它没有赋予所有新品牌「找有备案证工厂就能借证生产」的权利。[官方实施问答第26问](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/spscs/art/2026/art_2c532fed8fd94e179d83bd7a9c2ee461.html)

由此需要区分三个商业选择：

1. 我方作为普通食品或运动营养食品的委托方，按实际类别开展代工。
2. 我方作为某已有合规保健食品的经销商，采购并销售相应产品；品牌、标签及经营要求另核。
3. 我方持有适用的产品注册或备案身份，再按相应规则安排生产。

第二种不能自动满足「我方WPC80、我方配方、我方品牌」的全部要求。运动营养类特殊膳食食品与食品安全法下特殊食品的管理概念也不能混用。当前没有必要为了卖点先改变路线；应让拟议路线的提供方出示与我方身份相匹配的产品和生产依据。

## 四、原料归我方所有，为何仍可能拿不回来

### 1. 未付费用与留置权

民法典第783条规定了承揽成果的留置或拒绝交付及另行约定空间；第448—450条涉及企业间留置、约定不得留置及可分物价值范围。第775条另要求承揽人检验客户来料，不得擅自更换；第784条规定保管责任。[民法典官方文本](https://www.court.gov.cn/zixun/xiangqing/233181.html)

因此，「客供原料始终归我方」与「费用争议时如何提取原料及成品」应分别谈判。建议优先约定无争议款按期支付、争议款独立处理、未使用原料与合格成品可分别释放；对特定客户财产是否排除或限制留置，应写明对象和范围，并由合同审查确认效力。不能把法律留置问题简单写成工厂一律无权扣货，也不建议我方停付全部款项后自行搬货。

### 2. 库存可识别，才有条件讨论取回

企业破产法第38条确立通过管理人取回非债务人财产的路径。它不意味着合同上写了货权，任何状态下都能即时拿回等量粉体。[企业破产法官方文本](https://xzfy.moj.gov.cn/c/2021-01-06/487747.shtml)

本项目的证据准备应随粉体状态变化：

| 状态 | 应留存什么 | 主要不确定性 |
|---|---|---|
| 原包装未开封 | 批号、袋号、重量、库位、收料和定期盘点记录 | 是否实际存在，是否与他人料混放混记 |
| 拆袋待加工 | 拆袋去向、容器编号、封识、称量记录 | 失去原包装后如何证明仍是我方这批料 |
| 已加入工厂辅料 | 批配方、各方投料、在制品权属约定 | 混合形成的新物归属、如何分割或结算 |
| 已包装待放行 | 批号、实物数量、检验状态、货权及释放条件 | 不合格品不能作为正常合格品提走销售 |
| 已交物流或外仓 | 仓储／运输合同、收货证明、状态交接 | 实际保管人、费用和风险节点变化 |

这属于证据和交易设计，不是对任何候选工厂经营状况的指控。工厂破产、重整或发生争议时，具体取回范围、程序及相关费用需要结合事实处理。本轮未取得可完整核对的2020年修正司法解释全文，因此不对其逐条适用作进一步结论。

### 3. 不要先把原料卖给工厂，再假定仍可取回

如果改为「工厂买入我方原料，再向我方卖成品」，合同和开票反映的货权、债权可能已经改变；不能继续按纯来料承揽的逻辑管理。该结构可能有真实商业理由，但必须重新测算付款、质量责任和对方信用敞口，不能只为报价方便做形式转换。

## 五、蛋白质差异先查口径，再谈索赔

前轮已经解释干基与实物基准，本轮新增核查氮折算系数。ADPI的WPC技术资料列出的蛋白检测参考为AOAC 991.20及N×6.38；这属于该资料的技术口径，不自动替代中国产品的法定检验依据。[ADPI WPC标准](https://adpi.org/wp-content/uploads/2023/07/WPC-Standard-v4.0_2023.pdf)

**算术示例：** 同样以实物基准计，若测得总氮为12.00g/100g，分别乘6.38和6.25，会得到76.56与75.00g/100g，相差1.56个百分点；换算30g分别为22.968g与22.500g。这里只隔离系数变量，不是在为同一产品提供两种任选方法，也不是我方WPC80检测结果。

为避免各拿一份报告互相指责，原料准入、成品标示和争议检测至少统一以下六项：

| 必须统一的项目 | 不统一会发生什么 |
|---|---|
| 样品身份和取样批次 | 小样合格被误认为另一批大货合格 |
| 干基或实物基准、水分处理 | 把口径差当作生产损失 |
| 完整标准编号、年份及具体方法 | 不同程序的结果直接比较 |
| 蛋白折算系数及适用依据 | 同一氮含量出现不同蛋白数值 |
| 配方及其他含氮成分 | 总氮结果不能单独解释蛋白来源或配方真实性 |
| 报告修约、判定规则及临界结果处理 | 把四舍五入值当成无不确定性的绝对值 |

本轮检索到GB5009.5—2025发布信息及转载附录，但标准全文下载未成功，故不在本报告替最终配方指定系数或方法。检测机构应按现行标准、产品标准及实际配方确认，并写入委托单。[国家卫健委发布目录](https://www.nhc.gov.cn/sps/c100088/202503/e8a432507f7d4f08a877e76a9b0578ce.shtml)

新增检测预算也不应一律堆叠。是否增加氨基酸组成或其他真实性验证，应由原料风险与调查问题决定；本轮没有证据指向我方或候选厂家存在掺假。

## 六、验收证据必须把「样品」连接到「整批货」

《检验检测机构监督管理办法》第9条区分送检样品结果与样品代表性、真实性的责任。实验室报告不能替代供应链中的取样证明。[认监委原文](https://www.cnca.gov.cn/zwxx/bmgz/art/2021/art_52013105cec94dd6af8ef0f5aaf7743a.html)

对1吨来料、多个混料批或多个包装时段，建议形成如下证据链：

**原料批次与实际投料 → 混料批及包装时段 → 按适用方案抽样 → 封签与运输记录 → 实验室接收 → 报告 → 批次放行 → 出库客户。**

抽样方案应先定义批次、检验目的、项目和适用标准，再由质量人员／实验室确定样本数及方式；本报告不自行规定「抽几包就代表1吨」。理化与微生物项目可能需要不同的样品组织方式，不能默认把多个时段样品混成一份就满足全部要求。

| 文件 | 最少应回答的问题 |
|---|---|
| 抽样记录 | 谁抽、何时、从哪批哪个位置抽、按何方案、抽了多少 |
| 封样与交接记录 | 封签号、样品状态、保存条件、交接人及异常 |
| 检验委托单 | 检验项目、现行方法、产品类别、判定依据、报告用途 |
| 报告核验记录 | 报告真伪、批号、所检项目与委托单一致性、是否有分包 |
| 放行记录 | 未覆盖项目由何证据支撑，异常是否关闭，由谁批准 |

这不意味着每批都需我方另做一套全项检测。应先区分工厂已承担的出厂检验、我方查验及风险需要的抽检，避免重复付费，同时保留我方能独立核对的证据。

## 七、质量争议不能约定为「重检到合格」

2025年修正的《食品安全抽样检验管理办法》适用于监管部门组织的监督抽检和风险监测。其中第31条对微生物指标不合格等情形规定不予复检；第37条另有抽样过程、样品真实性、方法和标准适用等异议路径。不能把不予复检误解为完全不能依法提出其他异议。[官方现行文本](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_dec8874a13a64e12b0d49ff8b3ff0bd6.html)

双方内部商业验收不因此自动适用全部行政期限，但应避免合同声称可用私人复检推翻监管结论。建议把处理流程写成：

1. 确认问题类型与受影响批次，先隔离、暂停相关发货；必要的安全处置不等待争议定责。
2. 保存首次报告、原始批次和取样证据；双方核查是否存在样品混淆、口径或方法差异。
3. 对适宜复核的事项，按预先约定或双方共同确认的机构、方法、样品和判定规则进行调查；不得简单取平均或择优选报告。
4. 结合原料、环境、过程、包材和储运证据确定原因；合同费用分配与法定处置分别落实。

特别是微生物污染，后一次样品未检出不能单独解释前一次阳性或不合格。本轮不提供具体批次的放行判断。

## 八、预算还缺少「失败后如何收场」这一列

加工费低不代表总风险低。建议新增两个内部指标，均不作为会计或法律结论：

**在厂资产与预付敞口＝我方在厂原料／在制品／成品的分状态价值＋未形成已计价资产的预付服务款＋其他不可取消投入。** 同一笔原料、包材、预付款不能重复计算；剩余库存、已付定金与未来取消费分别列示。

**退出净支出＝已发生且应承担的服务及材料费用＋经证实的取消／处置／退运费用－应退预付款－可回收或可转用价值。** 实际责任仍按合同、履行事实和法律确定。

| 退出发生时点 | 需要查明的费用 | 应争取的证据和控制 |
|---|---|---|
| 文件或样品审核未通过 | 审核、检测、样品寄送 | 先明确收费与失败交付物，避免整个项目自动转为不可退 |
| 配方未通过感官或稳定性评价 | 已约定的开发服务、已采购辅料 | 版本、试制记录、原始结果及可使用范围 |
| 包材已下单、尚未投产 | 制版、已印膜、取消费用 | 供应商订单和数量、残余膜归属、可转厂性 |
| 已混料、尚未包装 | 混料和检验、在制品处理 | 在制品状态、剩余期限、能否转用及合法处置 |
| 成品异常或延期 | 隔离、仓储、检测、返工／销毁、物流 | 原因证据、补救方案及费用确认，不默认粉体可返工 |

民法典第777、787条涉及中途变更要求或解除承揽合同的损失承担。因此样品不满意、改包装或撤单是否免费，应在阶段任务中明确，不能把「随时可停止」理解为「没有任何退出成本」。[民法典](https://www.court.gov.cn/zixun/xiangqing/233181.html)

责任上限也要与自供原料匹配。如果约定工厂对一切损失最多赔加工费F，而在厂原料价值为R，R显著高于F时，条款可能无法覆盖原料损失。建议分别讨论材料毁损、一般延期、食品安全事件、故意或重大过失、第三方请求等事项，勿用单一总上限替代分析；具体效力与可赔范围须经合同审查，内部约定不能免除法定对外责任。

## 九、将1吨项目拆成四次授权，控制不可逆投入

这里建议拆的是任务与投入的授权，不是强制把生产拆成四批。

| 阶段 | 允许推进的事项 | 推进下一阶段需要的材料 |
|---|---|---|
| A：主体与原料可行性 | 核资质、原料规格、工艺与类别 | 实际制造主体、来料接收规格、目标产品路径 |
| B：样品及产线适配 | 按明确任务打样、测试袋型／下料／封口 | 配方版本、样品记录、实际产线验证结果与问题处理 |
| C：采购和生产锁定 | 经确认的包材、辅料采购及排产 | 标签定稿、分项报价、原料盘点、取消费和释放安排 |
| D：批次放行与交货 | 按合同完成检验、查验、交接及结算 | 批次记录、报告、物料对账、放行与交货凭证 |

不要用一个笼统「已确认样品」同时代替口味确认、法规审核、产线适配和保质期依据；不同确认应指向不同证据。分阶段付款比例和阶段价格仍待商业谈判，本轮不填入任意比例。

## 十、本轮对合作策略的实际建议

对我方自有品牌的30g条包项目，优先争取与实际制造主体建立可追责的生产关系；若必须经过服务公司或多重委托，先弄清其角色、资格、收费和交付责任，再评估多一层主体是否带来足够价值。

对西子等品牌企业，继续分开谈「原料销售」与「为我方制造成品」。原料销售可以作为独立商业选择，但不能自动证明我方自有条包项目成立。对特定客户的专供原辅料，官方问答另有具体边界，不能用「专供」两字把面向市场销售的30g消费品排除在委托生产管理之外。

本轮最应追加到厂家回件中的材料是：主体关系图、货权与提货安排、取样和报告对应方案、分阶段取消费用、原料及包材退出方案。已有的许可证、来料规格、产线验证、分项报价和条件排期继续保留。

截至本轮，仍不能判断哪家总成本最低、我方原料能否直接生产、每条可标多少蛋白、何时能交货，以及合同责任上限应定多少。决定这些问题的下一类证据是实际COA、配方、工厂回件和合同，而非更多营销网页。
