# 附件04｜经营测算与参数缺口

版本：2026-10-23。当前无本项目正式报价、核定税务口径、平台结算或订单数据。因此本附件提供可编辑模型及独立算例，不给盈利预测或最终定价。

## 1. 先统一口径

1. 成交分析按实际客户、实际订单分别记录；同一客户多订单不重复算新增客户。排除员工、自买及测试单并另存记录。
2. 记录原价、折扣与消费者实际支付；计算收入时只用实际交易金额，不能再次扣已经体现在实付中的折扣。平台补贴是否实际归商家、是否满足收入确认条件单独核实。
3. GMV、收款、财务收入和利润分别列示。主模型采用不含税销售收入；税率、可抵扣进项、附加税费及所得税由实际主体财务确认，不自动用13%。以下「经营结果」不等于税后净利润。
4. 首单模型以同一获客批次为对象，等待适用退款期和结算信息成熟。现金支出随付款日期另建现金流；在途、库存、平台待结算均不能当可用现金。
5. 样品赠送、优惠券、达人佣金、联盟费用、广告与返利各有唯一科目。同一费用不能在CAC和订单直接成本中重复扣除。
6. 商品销售成本指售出商品对应原料、加工、内包装及入仓等核定成本；外发快递箱和运费在履约项。若工厂报价已含内袋和礼盒，不在包装项重复计。
7. 食品退回不默认可再次销售。可回收金额仅在质量和财务认可可入账时扣减成本；模型默认没有回收收益。销毁、补发与损耗分别记。

## 2. 订单级可填模型

| 符号/字段 | 单位与定义 | 获取资料 | 当前值 |
|---|---|---|---|
| Q | 批次已付款订单数（单） | 订单导出 | 待填 |
| U | 批次新增且最终留存有效购买的客户数（人） | 去重订单及退款状态 | 待填 |
| S | 消费者商品实付总额（含税元） | 订单/支付对账 | 待填 |
| F | 退款总额（含税元），包括部分退款 | 退款对账 | 待填 |
| B | 已结算归属商家的平台补贴/其他交易对价 | 平台结算及财务分类 | 待填，不默认为收入 |
| T | 与净销售对应的销项税额 | 发票、红字与税务口径 | 待填 |
| R | 不含税净销售收入＝S－F＋符合条件的B－T | 财务核定 | 计算 |
| C | 本批次商品销售成本＋退货损失－获准回收价值 | BOM、库存、销毁和成本账 | 待填 |
| K | 外发包材 | 包材发票；核对C已含项 | 待填 |
| L | 仓储拣配与物流、逆向物流 | 物流/仓储账单 | 待填 |
| E | 平台/支付/联盟服务费实际净额 | 含退款退费规则的结算账单 | 待填 |
| J | 达人/合作伙伴佣金实际净额 | 合同及成熟结算 | 待填 |
| V | 售后补发、赔付、报废及其他变动服务费 | 售后明细；排除C/L已计部分 | 待填 |
| A | 可归属本批次的广告及获客费用 | 投放账单、样品及推广费用分配 | 待填 |
| O | 期间固定费用及研发/设计等适用摊销 | 人员、租金、研发检测等账单 | 待填 |

计算：

```text
产品毛利 G = R - C
产品毛利率 = G / R                         （R > 0）
投放前贡献 M0 = R - C - K - L - E - J - V
营销后贡献 M = M0 - A
贡献率 = M / R                             （R > 0）
期间经营结果 P = M - O
实际获客成本 CAC = A / U                    （U > 0）
首单可承受CAC = 首单投放前贡献总额 / U - 目标每新客首单贡献
```

不同业务的获客归因先写规则。若A中已含寄样的货品与快递，这些样品不能再计进销售订单C/K/L；也可以把样品单独设项目，得到「获客总投入」后统一并入一次。不要用「广告费÷全部订单」冒充新客CAC，也不要在收入里减了退款后又把退款金额作为费用全扣一次。

补货和库存模型：

```text
期末库存数量 = 期初库存 + 入库 - 销售出库 - 赠样出库 - 报废 ± 合规调整
采购现金需要 = 本预测窗口到期货款 + 包材/检测等付款 + 同窗口预计运营现金支出
可用现金 = 期初账上可支配现金 - 需保留的售后准备金 - 未列入上述需要的其他已承诺支出
资金缺口 = 采购现金需要 - 可用现金 - 预计在付款日前实际到账的结算款
```

同一到期付款只能在「现金需要」或「其他已承诺支出」出现一次，不能两边重复扣减。期初现金与预计到账额按同一预测窗口切分。这是计划模型，具体回款时间和保证金可提取条件要以合同和平台结算为准。销量上升但结算慢、库存增加时仍可能缺现金。

## 3. 独立算例：示例数据，非报价、非预测

以下为方便复核的统一不含税管理算例，与天源、蒙特威、任何OEM厂或平台报价无关。假设每付款订单均已发货，退款平均比例8%，退款商品无回收价值，以下广告费仅按付款订单分摊；正式CAC必须用实际新增有效客户数U重新计算。

| 项目 | 每付款订单示例（元） | 说明 |
|---|---:|---|
| 折扣后销售额P₀ | 100.00 | 已扣折扣、不含税的示例口径 |
| 退款抵减 | 8.00 | 按金额比例8%，非订单退款率 |
| 净收入R | 92.00 | 100×(1－8%) |
| 商品成本C | 32.00 | 已含内包装；均发货且无回收 |
| 产品毛利G | 60.00 | 92－32；毛利率65.22% |
| 外发包装K | 3.00 | 不含C中的内袋 |
| 仓配物流L | 6.00 | 示例平均值 |
| 平台与支付E | 4.60 | 示例净收入×5%，非真实费率 |
| 佣金J | 13.80 | 示例净收入×15%，非招商承诺 |
| 售后及变动服务V | 4.00 | 售后2＋变动服务2；不含已抵收入退款 |
| 投放前贡献M0 | 28.60 | 60－3－6－4.6－13.8－4 |
| 广告分摊A | 20.00 | 每付款订单分摊；不直接称新客CAC |
| 营销后贡献M | 8.60 | 贡献率9.35% |
| 1000个同类付款订单贡献 | 8,600.00 | 假设指标保持不变 |
| 固定费用O | 10,000.00 | 同期独立示例 |
| 期间经营结果 | −1,400.00 | 尚未覆盖固定费用 |

在该算例中，不计新增固定费用和供给限制，覆盖10000元固定费至少需要向上取整10000÷8.6＝1163单。若每付款订单A超过28.60元，则首单贡献转负；若要求每付款订单至少留10元贡献，A上限18.60元。上述均为模型推导，不是项目获客承受力。

### ±20%敏感性（示例数据，非报价、非预测）

其他项不变，只改变一项。退款比例的±20%为6.4%和9.6%，不是上下20个百分点。

| 改变项 | −20%情形每单贡献 | 基准 | ＋20%情形每单贡献 | 决策含义 |
|---|---:|---:|---:|---|
| 折扣后销售额P₀ | −6.12 | 8.60 | 23.32 | 此算例降价20%即转为负贡献，先算后降 |
| 商品成本C | 15.00 | 8.60 | 2.20 | 小包装与原料波动可快速挤压利润 |
| 每单广告分摊A | 12.60 | 8.60 | 4.60 | 投放扩大不能假定获客单价保持不变 |
| 金额退款率 | 9.88 | 8.60 | 7.32 | 仅反映此简化模型；现实逆向运费还可能增加 |

## 4. 价格与佣金的边界公式

仅在费用确实按净收入比例收取、税务已经统一、退款与出库关系符合假设时使用以下简化式；正式决策优先用上面的逐单账单法。

```text
P₀ = 折扣后、不含税、退款前订单销售额
r = 退款金额率；f = 平台等比例费率；j = 佣金率
k = 商品、包装、履约、售后、变动服务等固定到每单的成本
a = 每单获客分摊；m = 目标每单贡献
最低P₀ = (k + a + m) / [(1-r) × (1-f-j)]
最高j = 1 - f - (k+a+m) / [P₀×(1-r)]
```

分母不大于零时该组合不可行。最高j为负说明零佣金也达不到目标。阶梯费、最低收费、非退款佣金、分期补贴等必须改用实际费用，不能套比例。

## 5. 首单、复购和试用单独看

| 看板 | 必须报告 | 不接受的替代 |
|---|---|---|
| 首单 | 新客U、首单收入/成本/退款成熟度、首单贡献 | 用累计GMV、粉丝、意向人数代替 |
| 试用 | 寄出人数、签收人数、体验完成、正装付款、净成本 | 只报领取数、强制好评、买赠制造虚假复购 |
| 复购 | 首购批次、可观察天数、实际二购人数、二购贡献 | 尚未到消耗周期就假定月月复购 |
| 渠道 | 每渠道订单成本与贡献，佣金和服务工时 | 将低佣渠道高人工成本隐藏 |

复购率分母只用有足够观察时间的首购客户，并标30/60/90天观察窗。未验证前，决策模型的复购贡献填「未验证，不计入首单可亏损额度」。

## 7. Gemini旧财务沙盘的专项纠错

M01b曾假设首批3000盒正装、2000份体验装、总投入72000元、90天全部售罄、均价248元、直营30%及团长70%，进而声称398580元「净现金流利润」和82.8%净利率。这些均为历史AI沙盘，未取得相应报价、预算批准、订单或实收记录。

其列项合计72000元及481080－72000－10500＝398580元的算术可以复算，但算术正确不代表净利润成立：费用和税项不全，先把直营10%及团长佣金扣进「回款」后又以回款为净利率分母，现金流与损益混用；3000盒直接当3000单，又同时主推3盒装，箱数、订单数和快递费口径矛盾。

「直营卖300盒或团长卖600盒即收回7.2万元」也不成立于其自身费用设定：300×248×90%＝66960元，600×248×50%＝74400元；后者还没扣履约、税费、退款、人工等。若把体验装收入纳入回本，必须同步纳入其成本、实际成交与时间，不能暗含抵扣。收回初始现金后，余货继续销售仍有机会成本、履约、佣金、售后和税费，不能称「全部纯利润」。

旧招商798元三盒与298×3－150＝744元又存在价格冲突；45%—55%佣金对应359.10—438.90元佣金收入，不是360—400元「纯利润」。不继承该预算、价格、佣金或60%复购假设；统一用本附件参数表与真实成熟订单重算。


## 8. V2：包装溢价、补货量和现金管理

### 8.1 条包需要多少真实溢价

同配方、同总粉量、同等蛋白量比较。Δk为条包相对袋装每个订单增加的包材、加工、履约、损耗和变动服务成本；Δa为获客费用差，Δm为目标贡献差。固定开版和检测差异另列，按预计实际可售量分摊或在固定费用入账，不重复计。

在两方案退款率及比例费用相同的简化条件下：

```text
条包所需最低订单溢价 ΔP = (Δk + Δa + Δm) / [(1-r) × (1-f-j)]
```

消费者接受的实际价差低于ΔP，则不以便携作为溢价路线。若费率、退货、订单组合不同，分别用完整订单模型计算两方案贡献，不能套差价公式。水杯/分装盒赠品计入真实成本，不用赠品“原价”虚增价值。

### 8.2 首批量由三个上限共同约束

以同一基础销售单位计算，试用、赠样和正装单列转换，不将盒、袋、订单混用。定义：Qcash为资金风险上限内可承受数量；Qdemand为保守测试销量能消化的数量；Qshelf为扣除承诺客户剩余保质期、检验、运输时间后可消化数量。无销量记录时Qdemand只能是明确标注的测试上限，不能来自行业增速。

```text
首批采购量上限 = min(Qcash, Qdemand, Qshelf)
可行条件 = 供应商实际MOQ <= 首批采购量上限
```

Qcash先扣固定启动费用、未包含在单价的包材最低采购款、检测和售后/运营准备金，再按到期付款条件估算。不能将卖货后的潜在收益当作首付款来源。MOQ超过上限时调整试产或规格；不自动凑足MOQ。

### 8.3 每周补货看板

|字段|口径|决策用途|
|---|---|---|
| 终端净售出 | 最终消费者实际购买减退款；渠道进货单独列 | 判断需求，不以压货造销量 |
| 可售/隔离/临期库存 | 按批次和状态分开；不合格不计可售 | 判断可履约量和报废风险 |
| 库存位置 | 可售现货＋已确认在途－已分配未发货订单 | 避免重复下单；需求预测应排除上述已分配订单 |
| 保守周需求/补货提前期 | 从成熟批次估算并记录样本与波动；按确认交期 | 确定覆盖需求；短期爆单不直接年化 |
| 待结算与到期付款 | 平台到账日期、货款、费用逐周排程 | 判断短缺发生在哪一周 |
| 渠道库存及退货责任 | 能否取得实销、谁承担临期和退货 | 不能只看品牌已收款 |

建议补货触发点＝保守周需求×已确认补货周数＋经批准的安全缓冲；采购量仍受上述资金、需求和保质期上限约束。缓冲量无数据时留待填，不直接用固定库存月数。最低可用现金须覆盖下一采购窗口的确定付款和运营准备金；具体额度由真实账期及风险预算决定。

N40讨论的是大型乳企营运资本，不证明本项目可以获得账期。N37/N38/N41/N42的去库存与量价分析只转为管理方法，未采用其历史行情或预测。本模型也不据宏观报告计算本项目市场份额。
