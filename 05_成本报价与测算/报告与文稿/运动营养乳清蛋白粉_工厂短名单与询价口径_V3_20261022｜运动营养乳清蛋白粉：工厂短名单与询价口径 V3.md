## 统一询价与比价口径

GB 24154是产品标准，不能只凭网页写有该编号认定工厂生产许可覆盖目标产品。国家卫健委公布的截至2025年9月标准目录列有GB 24154-2015，另有已发布的第1号修改单。厂家应按投产时适用的标准及相关规定说明目标SKU归类，并提供对应资料。[官方标准目录](https://www.nhc.gov.cn/sps/c100087/202601/b8bc7bf0fd6243c1914d8c0708d9929a/files/食品安全国家标准目录（截至2025年9月共1725项）.pdf)、[第1号修改单发布说明](https://www.nhc.gov.cn/sps/c100087/202109/b264493ad4ca44cba765c4ea32f15c0e.shtml)

先让三家各报现有成熟方案，再对可比配方统一规格二次询价。下表是建议收集字段，不代表用户已确定配方、包装或订单数量。

| 统一字段 | 要求厂家填写／提供 |
|---|---|
| 实际生产主体 | 企业全称、生产地址、SC号、有效期及完整品种明细；与收款／签约主体不同时说明关系 |
| 产品归类 | 是否为运动营养食品补充蛋白质类粉剂；执行标准、现行标签样稿及相应检验报告 |
| 两类成熟方案 | WPC为主方案、WPI为主方案分别填写；混配产品说明各蛋白来源，不把原料等级当成成品蛋白含量 |
| 配方与质量 | 原料品牌／产地、配料表、成品蛋白质g／100g、糖与脂肪指标、口味、批次COA和保质期 |
| 包装与数量 | 每袋／罐净含量、每盒袋数、各方案MOQ、可报阶梯量、包材最低量及余料处理 |
| 完整价格 | 含税产品单价与税率；运费、打样、检测、设计制版是否已含；定制或专利许可费另列 |
| 履约条件 | 打样与大货交期、付款节点、报价有效期、批次验收及不合格处理 |

计算规则：每公斤成品价＝单件价格÷单件净含量（克）×1000；每件到货成本＝含税单价＋未包含费用按订单合格件数分摊。配方、蛋白含量、包装、订单量及税运口径一致后才比较价格。原料粉公斤价不得与成品OEM价格直接比较。
