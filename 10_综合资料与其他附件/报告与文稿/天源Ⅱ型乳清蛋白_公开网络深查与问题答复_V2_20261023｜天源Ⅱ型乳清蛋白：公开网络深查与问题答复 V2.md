# 天源Ⅱ型乳清蛋白：公开网络深查与问题答复 V2
核验日期：2026年10月23日｜内部研究｜在同日实物与价格核验基础上补充

**公开网络深查的结果：找到了两家企业的相关技术与项目资料，但仍未找到能把「天源Ⅱ型」对应到特定乳清原料等级、活性指标和人体效果的完整证据。高售价已知，特殊价值尚未核实。不能据此认定它没有特殊成分，也不能将其与普通乳清认定为效果完全相同。**

## 1. 对上轮悬而未决问题的直接答复

| 问题 | 本轮答案 | 证据状态 |
|---|---|---|
| 「Ⅱ型」是不是公认的更高级乳清？ | 本轮未找到该产品的型号定义或把「Ⅱ型」列为高级乳清等级的直接依据。现阶段只能保留为企业产品名称中的型号信息 | 未解决技术定义；不能自行映射为WPI、免疫乳清、二型胶原或人乳蛋白 |
| 是否有专利？ | 天源有关联专利公开文本；蒙特威也有乳清加工方法的授权公告记录 | 企业有专利与本款产品采用专利、具有特殊效果是不同问题 |
| 天源Ⅱ型是否有临床研究或第三方检测？ | 本轮未找到能明确匹配产品名称、配方和用量的公开报告 | 属公开检索未命中，不等于断言企业没有内部资料 |
| 蒙特威到底有没有原料生产背景？ | 找到政府项目公示、官网产品和工艺专利；并非仅有泛化的销售介绍 | 仍不能确定28万元／吨对应哪一型号或批次 |

| 100元／5克是否由乳清原料成本解释？ | 按用户原料报价，0.9克对应0.252元成本参照；未找到足以解释高售价的本款专属成本或效果证据 | 不能把参照成本当成天源实际成本，也不能倒算其毛利 |

## 2. 天源专利究竟能证明什么

### 已核实的两项公开文本

| 文献 | 实际内容 | 与照片中产品的关系 |
|---|---|---|
| CN112655769A《一种人乳闪释片剂及其制备方法》 | 以人乳为主要原料，结合赋形剂、冻干成型和单片包装；第一项权利要求包含人乳100份及其他配料 | 与照片的5克袋装「乳清粉、乳清蛋白粉、葡萄糖、麦芽糊精」不能直接对应 |
| CN110075054A《一种来源于人乳的人源性生长因子修复制剂及其制备方法》 | 人乳冻干粉与冻干水分装；说明书应用示例涉及皮肤喷涂等 | 外用制剂示例不能证明口服乳清饮料效果 |

来源：[人乳闪释片剂公开文本](https://patents.google.com/patent/CN112655769A/zh)、[人乳生长因子修复制剂公开文本](https://patents.google.com/patent/CN110075054A/zh)。

这里列的是已查阅的申请公开文本，不把“A”公开号表述成已确认的当前有效授权证书。也不据此断言企业只有这两项专利。

**一个重要的数字区别：**CN112655769A多个实施例写到人乳冻干片每片约0.9克，并用20毫升37℃水测试溶解。这里的0.9克是整片制品重量，不是5克乳清粉中的原料添加量。用户确认的「乳清原料添加0.9克」仍按用户提供信息保留；这处数字相同不能作为交叉验证，也不能用来推翻用户信息。

另检索到CN102200526B《一种鉴别人乳中掺入的牛乳的定性检测方法》的企业关联线索，但本轮没有取得足以完成权利人变更链核验的资料。其技术内容本身属于检测方法，不是天源Ⅱ型的配方或人体效果证据，因此未计入本款有效证据。

## 3. 蒙特威的新证据：生产项目与授权公告

**政府项目资料：**包头市生态环境局2025年12月26日拟审批公示列出的项目包含年产540吨乳清蛋白生产线，并提及乳清蛋白粉喷雾干燥工序。页面正文读取不稳定，本轮取得的是该政府网页的搜索索引内容。它支持存在相应建设项目资料，不能替代竣工验收、实际产量或成品质量报告。[包头市生态环境局项目公示](https://sthjj.baotou.gov.cn/gsgg/202512/t20251226_720859.html)

**授权公告记录：**查到CN115920460B《一种干酪乳清絮凝澄清及乳矿物质分离的方法》，公开专利记录显示授权公告日为2026年4月24日。其核心是乳清澄清及矿物质分离，属于加工技术；不是「Ⅱ型乳清」的技术定义，也不是免疫效果试验。当前权属与有效状态若用于合同，应以正式专利登记资料为准。[CN115920460B](https://patents.google.com/patent/CN115920460B/zh)

这是对上轮信息的补充：此前列出的CN116439289A《一种干酪酸性乳清预处理方法》是另一项申请公开文本，不要把两个号码当成同一项专利的前后版本。

**官网仍有规格缺口：**乳清蛋白粉产品页没有给出明确的WPC／WPI料号、蛋白纯度、乳糖、IgG、乳铁蛋白含量或批次检测报告。检索到的官网「蛋白含量90%以上」出现在酪蛋白产品介绍，不能移作其乳清蛋白规格。[蒙特威乳清蛋白产品页](https://www.mengteweisw.com/prod_view.aspx?id=232&nid=3&typeid=67)

因此，可以进一步评估蒙特威作为乳品原料供应商的条件，但仍不能从网站确认用户报价对应的具体规格。

## 4. 能否用「免疫活性」「低温工艺」「院线」解释价格？

这些差异需要分别验证，不能仅从名称或售价推定。

| 可能被提出的区别 | 足以开始比较的资料 | 现有材料能否支持天源Ⅱ型 |
|---|---|---|
| 蛋白质更多／纯度更高 | 成品蛋白质实测值、原料型号及添加比例 | 不能；0.9克添加量不等于0.9克纯蛋白 |
| 乳铁蛋白或IgG等成分更丰富 | 明确成分名称、每袋含量、检测方法及批次报告 | 未取得；配料名称也不能排除原料中天然存在少量这些成分 |
| 更好保留活性 | 可测量的活性定义、加工前后及保质期内数据 | 未取得；40℃以下冲泡说明不等于生产工艺证明 |
| 水解／小分子更特殊 | 水解程度、肽分子量分布、对应产品研究 | 包装未提供相应信息 |
| 人乳来源／专利配方 | 原料来源及供应链文件、对应专利权利要求 | 公司名称和其他人乳专利不足以证明 |
| 临床效果更强 | 与实际产品、剂量、目标人群一致的对照研究 | 本轮未找到匹配资料 |
| 医院／院线渠道 | 真实采购或合作资料；与产品效果证据分别核验 | 本轮未找到本款对应资料；渠道本身不证明效果 |

若销售方只提供一般乳清研究、企业的其他专利或使用者反馈，仍不足以填补本表缺口。另一方面，没有发现检测报告，也不能直接推断产品不合格。

## 5. 价格差距的结论没有改变

用户提供：天源100元／5克，乳清蛋白原料添加约0.9克；蒙特威原料最高28万元／吨。

- 原料价格换算：280元／公斤＝0.28元／克。
- 同添加量参照：0.9×0.28＝0.252元／袋。
- 添加比例：0.9÷5＝18%，不是成品蛋白质含量18%。

上轮同日核实的Myprotein香草900克成品，浓缩乳清399元、分离乳清559元，折合每5克约2.22元、3.11元；对应页面营养表蛋白质为72%和82%。价格为页面展示价，未核实结算优惠、运税及批次差异。这说明常规高蛋白比例乳清成品可以远低于100元／5克，不代表两者特殊效果相同。[浓缩乳清](https://www.myprotein.cn/p/sports-nutrition/impact-whey-protein-powder/10530943/)、[分离乳清](https://www.myprotein.cn/p/sports-nutrition/impact-whey-isolate-powder/10530911/)。

**当前最可靠的采购判断：将天源Ⅱ型列为「高溢价、特殊价值待证」的复合固体饮料；不把它直接列为高等级乳清原料标杆。将蒙特威列为「有生产项目和工艺资料、具体供货规格待核」的原料候选。**

## 6. 检索范围、排除项和未解决边界

本轮在公开网络中交叉检索完整产品名、Ⅱ／II／二型变体、简繁品牌名、企业全名、包装电话、SC号相关线索，以及专利、检测、临床、营养成分、原料规格和两家供货关系。工具包括Bright Data和网页检索；Bright Data一批任务出现502后使用后者补查。

对微信、抖音、1688、FoodTalks及CNKI、PubMed、临床试验注册网站进行了搜索引擎站点限定检索。这是公开索引检索，**不是逐站登录后的全量数据库审计**。微信一条候选链接因抓取服务访问限制未取得正文；部分政府网页超时。未访问私域群、未登录企业内部系统、未联系厂商，也未采购或送检实物。

排除的典型误匹配：雀巢天源素、诺天源／美瑞克斯、其他含Ⅱ型胶原的蛋白产品、作者邮箱含“Tianyuan”的乳清研究、专利引用列表中的其他企业、与本款无对应关系的排名软文。这些不能充当天源Ⅱ型证据。

到本轮结束，仍缺：①Ⅱ型正式定义；②本款完整营养表和成品COA；③蒙特威28万元／吨具体料号及COA；④本款专属人体研究或相匹配成分的剂量证据；⑤两家之间的实际供货或同规格证明。这些答案没有从已取得的公开页面中找到，报告未用推测补齐。
