# 蒙特威营销公司设立及运营方案

拟在内蒙古自治区呼和浩特市设立营销公司，由蒙特威科技持股70%、段宜宗持股30%，具体区县、住所待定。首期资金60万元，先配备7人，编制上限10人。经营测算以2026年10月31日为基准，M1—M12暂对应2026年11月至2027年10月。

公司主要承担乳清相关产品的开发组织、品牌经营和销售。拟研究20款产品，按五批安排，每批四款、两个月；量产逐款审批。销售目标为每季度100万元，按扣退款后的含税金额计算。

## 一 经营安排与资金结论

首年以P01、P02作为首发重点，完成原料适配、产品放行和付费试销；P05、P09在各自准入条件满足后加入主力组合。经营资源先集中于这四款，20款产品继续按计划开展研究、打样和渠道测试。12款分阶段销售、20款全部销售用于比较扩品对利润和资金的影响。

首批大货订单应具备四项条件：原料和成品检验合格；工厂报价、起订量、质量责任与付款条件明确；售价得到付费试销支持；现金足以支付货款、工资和税款。任一条件未满足，先安排补证、试产或谈判，暂缓大货投入。

四款方案月末现金最低为-5.59万元。将前三个月的收付款安排到具体日期后，最低为-10.09万元；若保留10万元安全余额，尚需准备约20.09万元，资金合计约80.09万元。后九个月目前按月末预算，实际签约后还须细化付款日期，全年资金峰值可能继续变化。

按现有采购和回款假设，60万元不足以支持既定销售节奏及10万元安全储备。经营上有两条选择：取得更小的滚动交货批量和更有利的账期、回款条件；或落实追加资金。条件未落实前，应控制首批采购规模。

24.88%为按60万元股权投入计算的账面ROI。追加股权后须扩大计算分母；采用借款时须计入约定利息和偿还安排。股东实际现金收益以依法决定并支付的分红为准。

## 二 资料基础与待办事项

方案主要依据企业提供的原料工艺与公司资料，以及既有营销研究、五款功能产品研究、WPC来料代工研究、十话题研究、WPI894/895资料和乳清水解综述。

截至2026年10月31日，项目尚未补充本批原料COA、正式代工报价和已成交订单。公开资料、待核业务条件和预算假设分别列示。工厂公开介绍用于筛选供应商，论文用于设计试验；正式承接条件与产品性能以本项目的书面回件、试产和检测结果为准。

原料与成品质量、工厂履约、付费需求和财务核算分别验收，具体资料与责任见第十章。

## 三 交易安排与股东治理

### 首期采购与委托生产

首期优先询价受托厂采购原辅料的品牌定制全包OEM。现有资料显示，成品仍待开发，尚无可直接经销的已验证SKU。全包方式可减少营销公司采购、管理原料的工作，但是否节约现金，要看含税报价、MOQ、付款条件、剩余包材归属和质量责任。蒙特威自供原料取得COA、通过适配试产且具有全成本优势后，再切换来料代工。首批3—5款先完成技术筛选，集中1—2款取得付费和复购记录，再决定其余产品的大货安排。

全包与来料两种方案应按相同质量、交货条件和销量比较，重点核单位贡献、首单不可撤回付款及13周现金最低点。当前60万元预算宜少占原料和专版包材。既有品牌成品购销可保留为备选，其销售额暂不列入首发预测。

|结构|合同与货物控制的实际安排|收入与利润如何看|首期现金与主要责任|适用条件及限制|
|---|---|---|---|---|
|A 成品采购经销|合格供货方供应可售成品；营销公司按约验收后控制库存，再向渠道或消费者销售|如果实质上为主要责任人，按商品收入与采购成本计算；采购成本单独核算|主要占用成品采购、仓配、渠道账期；仍须履行食品经营、进货查验、储运、售后及宣传等相应责任|适合成熟产品、小批可补货、供货方角色真实明确的验证。若营销公司实质组织委托，按实际委托关系认定责任|
|B 营销公司持原料委托生产|营销公司控制原料，并委托工厂形成在制品和成品；原料、余料、余膜、报废和质量责任须写清|销售收入减原料经济成本、辅料包材、加工、检验损耗、仓配和销售费用；母公司原料按经济成本或约定交易价格核算|前置支付更多，原料与包材MOQ可能早于销售；需要委托方制度、工厂监督与批次放行接口|适合原料优势已经过规格、工艺、报价和良品验证，销售能消化MOQ，现金可承担的产品。建议随验证转入，逐剂型核适配性|
|C 服务收费/真实代理|实际商品经营主体控制商品、定价及履约，营销公司提供内容、直播、渠道或代理服务；是否为代理看事实|收入为约定并满足确认条件的服务费/佣金；商品GMV仅为代运营规模。收入100万元与GMV100万元是不同目标|库存可以较轻，但工资、内容制作、垫付投流和服务费账期仍占现金；直播选品、内容等责任不会因不持货而消失|适合暂不承担库存的能力验证或单独服务项目。服务费率、回冲、验收和欠款必须约定，与A/B采用各自收入口径比较|

委托生产进一步分为B1全包OEM和B2来料代工：前者由工厂采购原辅料，后者由营销公司持有原料。两者的主要差别在采购、库存和付款组织，营销公司均应按实际委托关系履责。全包报价用BOM拆项校核，明确含税价格、未包含项目、余料余膜及价格调整；取得正式报价后替换估算，原料费只计一次。

委托关系须结合品牌、产品标准、合同与实际业务判断。2026年12月1日起实施的《食品委托生产监督管理办法》覆盖经营计划期，应落实委托方和受托方资质、合同、报告、监督及标签要求。[来源S04]

收入总额或净额由交易实质决定。执行企业会计准则时，应结合转让前商品控制权、履约责任、存货风险和定价权，判断主要责任人或代理人身份。适用会计制度由财务核定，商品销售与服务收费分别核算收入和贡献。[来源S01]

交易档案记录主体角色、货权与风险转移、发票验收和付款时间、责任与费用。母公司、营销公司、代工厂、仓配、平台及达人分别列明全称和收付款安排。

### 关联定价与股东权益

70/30决定股权收益的归属，关联交易还会影响双方的实际利益。母公司如供应原料或收取品牌费，可先取得相应交易收益，再参与营销公司利润分配。因此，双方应同时审阅关联价格和营销公司损益。

在产品当期全部对外售出、暂不计所得税和其他关联费用的情况下，设对外收入为R，母公司原料实际经济成本为C，关联原料转移价总额为T，营销公司其他对外成本费用为K：

- 营销公司利润＝R－T－K；母公司原料利润＝T－C。
- 合并观察的对外经济利润＝R－C－K，内部T抵销；未售存货中的内部利润不能提前当作集团已实现利润。
- 母公司综合权益收益示意＝T－C＋70%×（R－T－K）；段宜宗归属收益示意＝30%×（R－T－K）。
- 仅将T提高Δ，在上述限定条件下，整体经济利润不变，但母公司综合权益收益增加0.3Δ，段宜宗归属收益减少0.3Δ。税负、少数股东权益、存货未实现利润和实际分红另由会计处理。

关联价格应在首批订单前确定。优先取得同规格、质量、税费、账期和交货地的可比报价；缺少可比价格时，核成本依据与约定加成。季度复核价格，已确认订单原则上不追溯调价；返利、运费和不合格原料更换纳入一并比较。原料赊购仍记成本和应付，股东借款单列融资。

双方签署章程和股东协议前，完成以下十项安排：

**出资安排。** 分列注册资本、认缴期限、实缴、股东借款及设备等投入。按比例现金出资时分别为42万元、18万元；由股东提供凭证，财务和登记经办核对，以实际到账确认。

**经营授权。** 预算内日常事项由授权人员执行，预算外支出、借款担保、关联交易及品牌处置单列审批权限。起草人提出金额标准，双方结合现金能力确认，并约定禁止拆单规避审批。

**关联定价。** 产品和财务共同编制原料、服务价表，附规格、成本或可比依据，明确调整周期、异议处理、审议回避和替代采购机制，由双方审阅后执行。大批采购应先有价格依据。

**供应质量。** 区分原料不合格、工艺不适配和成品失败的原因与责任，约定检验权、复检、换料、延期及索赔资料。产品质量负责人、供应方和法律顾问共同落实。

**品牌与配方。** 权利人提供商标、配方等权属文件，明确授权类别、区域、渠道、期限，以及终止后的库存销售期限；包装源文件、账号和客户数据一并约定归属，由法律顾问审阅。

**资金与印章。** 公司账户统一收支，制单、复核、网银和印章分别管理；每月核银行余额，垫付款明确凭证与报销期限，出纳经办与复核分离，外部会计参与复核。

**股东报表。** 财务每月向双方提供同版本损益、13周现金、库存及应收账龄、关联往来和预算差异，经营负责人说明原因与处理安排。

**利润分配。** 会计先核弥亏、公积、可分配利润及支付能力，再提交股东决议。利润归属和实际分红分列，分红时间以公司现金安排为依据。

**经营激励。** 工资、绩效、销售佣金、服务费与股东分红分别计提。经营负责人提出以回款后贡献为基础的激励办法，财务核重叠计酬及退货回冲。

**退出与争议。** 双方与法律顾问明确退出条件、估值基准日、应收及库存减值、品牌客户交接、未结质量索赔、僵局调解和争议解决。回购价格及付款安排须先评估承受能力。

按出资比例表决时，70%已超过普通及特别事项的相关门槛，30%不自然享有否决权。双方如希望关联交易、品牌处置等特定事项共同同意，应在章程和股东协议中依法约定，并与法定权限衔接。[来源S05]

治理可采用一名董事、一名经理、一名监事的简化安排，设置及任职条件按公司法和章程落实。考虑关联交易较多，建议保留监督岗位。经理依法由董事决定聘任，董事、高级管理人员不得兼任监事。治理任职和员工7—10人编制分别管理，经营权限以授权文件为准。登记前核准母公司法定全称、执照和投资权限。

### 办理顺序与时间

股东和资本方案确认 → 地址/名称/范围锁定 → 章程与任职/授权 → 线上申报与本人实名 → 领照及同步食品备案 → 受益所有人备案、印章、银行税务用工 → 品牌授权和工厂审核 → 产品配方标签/检测/委托合同与报告 → 店铺审核、仓配试单 → 食品放行销售。

登记与开户筹备暂按2—4周安排，具体时长受住所核验、银行实查、补件、商标及产品许可影响。规费、代办、银行服务和保证金分别记账，当地减免费用以实际政策和办理结果为准。

### 测算范围与假设

财务模型覆盖20款产品、3类渠道、12个月，共720条销售记录，并逐款计算生产与库存。工作簿可切换四款、十二款和二十款组合，均按销售目标倒推。实际订单、有效报价及放行记录另建业务台账。

### 后续安排与暂停条件

M1—M2筛选首批四款，优先P01/P02放行及付费验证；M3—M4推进运动营养和外购WPI，P05合格后加入主力；M5—M6推进部分代餐、乳粉，P09按类别验证后销售。M7—M8在主力贡献、库存和回款稳定后推进棒类；M9—M10决定即饮、清爽及水解路线是否量产。M11—M12依据复购、利润与现金安排第二年度产品组合。

出现以下情形应暂停相应投入：安全、标签或许可条件不满足，停止放行；正常价试销获客后贡献不足，暂停付费扩量并调整价格、成本或渠道；临期风险或终端滞销，暂停补货；新增承诺导致现金无法覆盖到期款和储备，先改规模、账期或补资金；连续两轮改进仍有技术缺陷，停止该路线常规投入。

暂停记录应包括负责人、原因、证据、处置范围和恢复条件。食品安全及许可按法定要求执行，经营指标调整须保留原标准、批准人和调整理由。
