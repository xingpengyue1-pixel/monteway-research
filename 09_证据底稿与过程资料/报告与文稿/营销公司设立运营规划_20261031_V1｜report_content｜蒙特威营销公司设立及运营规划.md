# 蒙特威营销公司设立及运营规划

适用对象：蒙特威科技、段宜宗及拟设营销公司经营团队。注册城市为内蒙古自治区呼和浩特市。股权比例为蒙特威科技70%、段宜宗30%。规划基准日为2026年10月31日，版本V1。

本规划优先落实产品代工和销售组织。首期资金按60万元、启动编制7人、每季度扣除退款后的含税销售额100万元测算，人员上限10人。计划月份M1—M12暂对应2026年11月至2027年10月；实际启动顺延时，应同步重排销售、产品放行和政策适用日期。

本规划中的成本、薪酬、渠道价格、回款和销量均为可替换预算条件，尚未取得本单有效原料报价、OEM报价、实际订单及完整产品放行资料。测算结果用于确定询价、定价和资金条件，不构成采购承诺或收益保证。

## 一 经营结论与启动条件

建议在呼和浩特设立有限责任公司，由营销公司集中承担品牌、产品需求、委托生产管理、销售、客户服务和经营核算；原料供应、食品生产和必要研发检测分别由具备条件的主体承担。首六个月配置7名员工，形成12款开发候选，商业销售集中在2—4款主力；20款完整开发排程分为五批，每批四款、两个月，覆盖M1—M10。

季度100万元可以作为经营挑战目标，但当前资料不能证明已具备相应订单。目标情景下，前六个月不含税收入198.02万元、税后净利润6.13万元；首十二个月不含税收入396.04万元、税后净利润15.02万元。相对60万元计划首投的账面ROI分别为10.22%、25.03%。

60万元能否支撑经营取决于采购和回款条件。保守周转假设下，第2个月现金缺口4.63万元；如另留10万元安全现金，须准备约14.63万元追加资金，资金总额约74.63万元。若通过订单和合同将库存控制为半个月、下一轮采购预付比例降至20%、当月回款达到80%，模型最低现金为19.77万元，可在60万元内启动。这些条件必须先落实，不能由模型替代合同。

不建议开业即配满10人。按相同销售目标，10人情景首年净利润为-3.75万元，工资规模会吞掉经营利润。首年优先争取稳定毛利与现金回款，扩编由增量贡献决定。

## 二 公司设立与股权治理

建议公司名称按“内蒙古＋蒙特威相关字号＋营养科技/食品科技＋有限公司”方向准备3—5个候选，最终以名称申报和商标核查结果为准。“蒙特威科技”在登记文件中必须替换为营业执照上的完整名称及统一社会信用代码；现有资料存在“科技”和“生物科技”名称差异，需核实变更或主体关系。

经营范围以实际业务和登记系统规范用语确定，优先覆盖食品销售（仅销售预包装食品）、食品互联网销售（仅销售预包装食品）、市场营销策划；确有业务再加入技术服务、供应链管理等。不以营销公司经营范围替代食品生产许可。

建议注册资本与资金能力匹配。若双方决定注册资本60万元、按70/30全部货币实缴，蒙特威科技应投入42万元、段宜宗18万元。该数字是建议方案，当前尚不能视为已同意的付款义务。若60万元由一方先行提供、部分属于股东借款或段宜宗股权涉及服务换股，应分别签署并核算，不混记为两方同比例实缴。新设有限责任公司认缴出资应按章程约定自成立之日起五年内缴足；运营劳动本身不能直接作为法定出资财产。[R01]

70%持股在按出资比例表决时超过普通事项过半数和特别事项三分之二门槛，段宜宗30%没有天然否决权。建议章程和股东协议具体约定关联采购、增资稀释、借款担保、品牌授权终止、超预算支出、利润分配和股权退出的表决与保护机制，由双方选定法务审查可执行性，不直接写成双方共同控制。

治理可采用一名董事、一名经理、一名监事的简化架构；关联交易较多时建议保留监督岗位。董事、经理与监事依法不得违规兼任，治理任职与7—10名员工编制分别管理。经理按章程由董事依法决定聘任，不把段宜宗持股自动解释为已任总经理。

### 办理顺序与管理窗口

股东和资本方案确认 → 地址/名称/范围锁定 → 章程与任职/授权 → 线上申报与本人实名 → 领照及同步食品备案 → 受益所有人备案、印章、银行税务用工 → 品牌授权和工厂审核 → 产品配方标签/检测/委托合同与报告 → 店铺审核、仓配试单 → 食品放行销售。

筹备可按2—4周管理窗口组织，但这是项目排程假设，非政府办理承诺；注册地址、银行实查、补件、商标或产品许可可能改变时长。注册规费、代办费、银行费、保证金分别记账，未核实当地免费政策前不承诺“零费用”。

## 四 产品与代工实施方案

### 二十款产品的预算成本与定价

成本按每个拟开发销售单位列示，采用小规模纳税人不可抵扣采购税的含税到仓口径。先以WPC80净税100元/kg、WPI净税180元/kg、逐款原辅料及包装工费测算，再按原辅料/包材/加工13%、检验6%、入仓运输9%的预算税率计入不可抵扣税。实际税率及含税报价必须按供应商发票替换，不得给含税报价再加税。

基准公式为：（原辅料净值÷成品得率＋包材净值＋加工净费）×1.13＋检验净费×1.06＋入仓物流净费×1.09。低值采用WPC85、WPI165元/kg，部分辅料、包材加工运输较基准下降10%；高值采用WPC120、WPI210元/kg，相关项目提高15%、检验摊销提高50%。这是预算敏感性区间，不是报价置信区间。水解和澄清原料在相应SKU其他原料项单列，不按普通WPC价格替代。

直营净价扣除增值税及退款，按1%增值税的实际含税成交价等于净价×1.01。经销净价基准为直营的70%，企业团购85%；各渠道销售收入份额为50%、35%、15%。因此综合单价系数应为1÷（50%÷1＋35%÷0.70＋15%÷0.85）＝0.85，不能对销售额份额直接算术加权价格。

### 工厂选择与下单包

从既有候选中优先询衡美/吉美、天益/天利，再比较艾兰得、康比特等路线；这些名称只是询价线索，尚不是本项目已准入或已承诺接单的工厂。逐一核实际合同主体和生产地址，禁止拿集团品牌证照代替受托生产主体SC。

统一询价回件至少包括：实际主体及SC品种；接受客供WPC的条件；配方版本及原料税票；500/1,000/3,000盒MOQ与混料最小量；彩膜外盒最低采购量与余料归属；打样、检测、稳定性、制版、清线换线、加工、运费分项；得率、超装、留样及损耗责任；订金、尾款与分批发货；可排产时间及前置材料；配方/IP、质量监督、召回和违约责任。

拟定采购评分可使用“准入与质量为硬门槛，综合比较全成本、MOQ占款、交期、来料接受和售后”。不以最低单价单独选厂。付款节点优先争取20%订金、检验合格及分批交付后结余款；若对方只接受30%或更高预付，按真实条款回算。

2026年12月1日起，按《食品委托生产监督管理办法》落实委托方资格、监督能力、书面合同、双方各自报告和标签信息；合同签订后10个工作日内的报告要求纳入双方责任表。2027年3月16日新标签标准实施，应在第二批包材定版前完成新旧规则切换审查，避免囤积失配包材。[R06、R07、R10、R11]

### 价格及渠道利润纪律

直营不以吊牌价考核利润，按真实成交净价计算；经销基准不低于直营净价70%，企业团购85%。特殊折扣须逐单测算原料、代工、仓配、佣金和信用成本，按贡献审批。关联母公司原料按合同正常计价，集团内部利润不计作营销公司额外收益。

渠道费用率按净收入计：直营广告18%、平台4%、提成2%、履约4.5%、售后损失1.5%，合计30%；经销分别2%、0、4%、2.5%、0.5%，合计9%；团购分别2%、0、4%、3%、1%，合计10%。按收入份额加权，销售变动费用率为19.65%。售后损失仅计退款之外的破损、逆向物流等，已扣退款不再重复扣。工资外的销售奖金已含提成预算，不再另设无来源的奖金池。

广告费只是销售费用的一部分。预算总净收入/广告费约10倍是混合渠道预算比，不能当作真实归因ROAS。直营广告ROAS需用广告实际带来的退款后净收入÷对应投放费单独计算；未有归因数据，不宣称已达成投放回报。

## 八 经营测算与投资回报

### 模型口径

本模型为2026年11月至2027年10月的条件性经营预测，非已发生财务报表。四款主力满配后销售收入权重为P01 40%、P02 30%、P05 20%、P09 10%；未放行月份，仅在已放行主力之间归一分配。其他16款默认销量为零。跨SKU数量是不同包装销售单位的合计，不能直接称“相同罐数”或换算为原料吨数。

年400万元含税目标暂按增值税小规模纳税人测算，不含税收入为含税销售÷1.01，进项税不抵扣。销售额超过相应起征点，基准不采用免税。附加税暂按实缴增值税的6%计。符合非限制禁止行业、应税所得不超300万元、人数不超300、资产不超5,000万元等小型微利条件时，2027年底前所得税有效税负按5%；若不符合条件，另列25%情景。优惠不向2028年自动延伸。[R13—R19]

所得税按自然年处理：2026年11—12月亏损结转到2027年；账面利润暂等同税务可抵扣损益，无税务调整的假设须由会计复核。月度增值税和所得税按应留现金预提，表内期末现金为扣除税款准备后的可用现金，不代表税局逐月扣款时点。设备55,000元按36个月、零残值折旧；无借款及利息、无分红、无未批准补贴、无终值变现。

保守周转为当月收款65%、剩余次月收取；期末商品库存按下月成本1个月计，另预付下下月补货成本30%，代表不同批次，避免对同一批货既列库存又列预付款。无供应商信用期。期末采用持续经营，M12后仍保留稳定库存、预付及应收，不为美化现金在最后一个月全部清仓回款。现金低点为月末口径，月中集中付款可能产生更大缺口，执行时必须另做逐周、逐付款日的现金排程。

### 股东收益示意

在双方按42万元/18万元货币出资、利润分配比例合法约定为70/30、先弥补亏损且法定公积尚需计提的示意下，若以首年累计净利润15.02万元计提10%法定公积，可分配利润上限约13.52万元。假定全部分配且满足资金及决议要求，蒙特威科技取得约9.46万元；段宜宗税前股息约4.05万元，按20%股息个税后约3.24万元。母公司符合境内居民企业直接投资股息条件时适用相应免税规则。[R01、R20、R21]

上述为分配规则演示。基准方案首年不安排分红，以完成自然年度结账、弥补亏损、依法提取公积和满足周转后再作股东决议。30%股份不等于每月销售额的30%，总经理工资也不能直接冲抵应计股息税。
