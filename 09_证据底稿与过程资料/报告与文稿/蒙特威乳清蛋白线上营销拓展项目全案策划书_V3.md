## 第一章　全案总纲与战略定位（Executive Summary）

### 一、项目破局背景与核心经营命题

内蒙古蒙特威生物科技有限公司（位于包头市土默特右旗新型工业园区）拥有鲜奶深加工、酪蛋白（环评规划3,000吨/年）、稀奶油（5,000吨/年）、乳清蛋白粉（环评拟建口径540吨/年，含超滤及喷雾干燥环节）及乳糖（3,000吨/年）等扎实的产业基础与专利技术线索（如CN115920460B干酪乳清絮凝澄清及乳矿物质分离方法）。

在从“上游B端乳基原料车间”向“高附加值B端工业应用定制 + C端营养健康消费品牌”跃迁的启动初期，项目面临三大核心命题：
1. **产品现状与合规重构**：目前企业仅有乳清蛋白原料（拟议以WPC80为主），尚无现成可售的C端零售成品；历史遗留的《V5包装标准样稿与私域QA手册》残留未经本品实测证实的“进口原料、临床营养、术后/放化疗剂量”等高危表述，亟需通过科学的产品立项、受控事实卡与合规审查建立安全底座。
2. **渠道基建与组织承接**：传统制造端缺乏直接触达抖音、视频号、小红书的C端内容矩阵、百人级带货达人/渠道合伙人招募承接体系与小单快反能力；同时A线B端原料拓展亦需建立“应用痛点诊断—受控试样—同条件报价”的标准漏斗。
3. **顶层机制深度绑定**：面对前6—10周无成品销售期的深水区筹备，单纯的外部代运营或松散顾问无法实现风险共担。因此，双方确立了**“新设蒙特威营销公司（蒙特威约70%、潜势约30%）+ 母公司全额注资或借款 + 启动期服务费与利润分成过渡至股权分红 + 潜势派驻5名核心骨干全职入驻（薪资差旅进营销公司预算）+ 双方共管”**的顶层架构。

| 方案维度 | 路径A：认缴制工商实股登记 ＋ 母公司首期注资/专项借款 ＋ 三期考核成熟（推荐） | 路径B：首季身股（分红与共管权）先行 ＋ D90达标转工商实股 |

### 三、启动资金与两阶段收益衔接机制（「服务费+分成」→「股权分红」）

为解决“前6—10周成品尚在打样生产、营销公司无C端现货销售现金流，但5人全职团队与招商筹备必须满负荷运转”的客观矛盾，收益分配采取严谨的**两阶段过渡衔接机制**：

1. **阶段一：项目启动与市场验证期（采用「启动期服务费 ＋ 利润分成」）**
   - **驻场预算与启动期服务费**：潜势派驻5名全职核心骨干的基础薪资及差旅筹备费全部纳入新设营销公司预算（由母公司注资/借款资金池按月核发）；在此基础上，启动期服务费的具体核定标准、是否与5人驻场基础薪资差旅实行“总额包干”或“基础报销+增量服务费”，以及A线/B线早期成交的**利润分成比例与计算基数**（以扣除退款、直接产品成本、平台扣点及达人佣金后的净贡献毛利为基数），在《合资与管理入股补充协议》中明确锁定（具体数值当前标**待核**，严禁同一笔人力或服务成本在两处重复计提）。
2. **阶段二：业务常态化运营期（切换为「70% : 30% 股权分红」）**
   - **切换触发条件（待审定）**：当营销公司完成D90首季验收、首批产品进入稳定销售回款周期且累计净现金流达到约定阈值（或自第4个月/D91起），正式停止阶段一的“启动期服务费+过渡利润分成”，全面切换为常态化公司治理模式——5名全职人员作为营销公司正式定编高管与主管领薪，公司税后可分配利润在按约偿还母公司股东借款（或计提安全垫）后，严格按**蒙特威约70% : 潜势约30%**进行股东分红。

### 一、首季度（D1—D90）六大预算模块与1吨三拆成本模型

1. **1吨WPC80多款式拆分批次成本公式**：
   $$\text{外部增量总支出 } E_{\text{总}} = \sum_{k} (N_k \times V_k + F_k + A_k + L_k), \quad \text{完整批次总成本 } C_{\text{总}} = C_{\text{原}} + E_{\text{总}}$$
   其中 $C_{\text{原}}$ 为我方1,000kg WPC80内部结算总成本，$N_k$ 为第 $k$ 款合格交付条数，$V_k$ 为每条变动加工费，$F_k$ 为各款卷膜版费与开机清场固定费，$A_k$ 为外购功能与风味辅料费（CaHMB、氨糖、真椰浆粉、抹茶/可可/冻干果粉、赤藓糖醇等），$L_k$ 为试制/出厂检测与物流费。未耗用的卷膜MOQ余料单列包材库存，但全额计入首批现金支出峰值。
2. **六大刚性合规与经营红线（一票否决）**：
   - ① **严禁未定主体先对外以新股东或独家总代名义签约**；
   - ② **严禁未测COA先标“每条24g蛋白”**；
   - ③ **严禁B2女性款使用WPC80时冒充“100%分离乳清WPI或0乳糖不长痘”**；
   - ④ **严禁B3中老年CaHMB款或原味款无证宣称“特医食品FSMP、术后伤口愈合、治疗肌少症或蓝帽子增强免疫”**；
