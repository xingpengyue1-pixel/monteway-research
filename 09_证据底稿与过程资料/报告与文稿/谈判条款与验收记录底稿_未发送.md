## 二、合同中需要具体落地的十二件事

| 议题 | 建议谈判表达／要求 | 待填事项 |
|---|---|---|
| 受托及再委托 | 列明实际工厂和工作范围；换址、主要工序转委托须事先书面确认并核准资格 | 名称、地址、范围、变更流程 |
| 来料识别 | 按批次登记、可盘点；未经授权不得替换、借用或投入其他订单 | 标识、库存报告频率、盘点方式 |
| 在制品货权 | 分别约定未用原料、加入辅料后的在制品和成品归属 | 估值及混合后结算办法 |
| 留置与提货 | 无争议款按时结算；明确客户财产的留置限制或排除、争议款及可释放货物处理 | 范围、期限、担保／解决方式 |
| 原料检验 | 数量、外观、文档、实验室放行分开；不合格及时通知、隔离和复核 | 时间、项目、接收标准 |
| 交付成果 | 实物与批次、生产、检验、物料对账资料一起交付 | 文件列表、可脱敏范围 |
| 取样证据 | 按适用方案抽样、封签、交接，样品必须关联实际生产批 | 抽样人、方法、数量、保存 |
| 质量争议 | 先控制风险，后按原因分责；不以再次检验合格自动推翻首次异常 | 机构、方法、规则及费用 |
| 变更与取消 | 口味、配方、膜版、交期变更书面记录；取消费用有依据 | 已发生费用、不可取消采购 |
| 剩余资产 | 原料、半成品、膜、盒、版辊分别列明返还、转用或销毁条件 | 库存、运费、保存与时限 |
| 责任范围 | 对材料毁损、延期、食品安全及第三方请求分别讨论 | 责任上限、除外及保险证据 |
| 报告与管理 | 按实际生效规则及属地要求执行报告、监督和标签审核 | 双方负责人及留存记录 |

以上期限、数量、比例均未填，不能被理解为对方已接受或行业统一条件。约定不得排除法定食品安全责任和监管义务。

- 取样方、取样目的、方案及依据、取样位置／数量：待填。
- 取样、交接、收样日期与保存条件；异常情况：待填。
- 检验项目、标准完整编号及年份、具体方法、判定依据：待实验室确认。
- 蛋白检测的水分及干基／实物基准、氮折算系数及依据、修约规则：待确认。
- 检验是否分包、分包机构及项目、报告真实性核验方式：待确认。
- 样品余量、保存及争议处置安排：待确认。

这里不自行设定微生物抽样数量，也不假定第三方报告覆盖法定全部放行项目。
