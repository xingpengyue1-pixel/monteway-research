# 研究计算与可填写记录

所有演示均为人工构造，不是企业实绩。工具只计算输入对应结果，不判定配方合法、产品质量、可上市性、公司财税或市场可行性。

## 运行方法

在本目录运行：

```bash
python3 research_models.py 原料产出_空白输入.json
python3 research_models.py 原料产出_教学情景.json
python3 -m unittest -v test_models.py
```

未填参数为null，输出missing_input。只有真实为零才能填0。比例用小数，例如98%=0.98；不要填98。现金用同一货币，模型不自动换汇。金额演示均无实际业务含义。

## 八个模型

|model值|用途|边界|
|---|---|---|
|batch|逐款原料、混合、灌装、剔废、样品及可售数量|得率为可灌装粉得率；包装剔废另算，避免重复。比例剔废向上取整；实绩用实际记录核对|
|protein|干基、水分和配方占比的理论WPC蛋白带入|不包含其他配料贡献，不作营养标签定值|
|cash|按事件先后计算融资前缺口和融资后余额|同日沿用输入先后；没有收入确认或税务功能|
|creator_forecast|期初及分队列的D90期望值|不是达标概率，也不是实际人数；缺值不推算|
|leads_required|给定缺口/转化/存续反推最少线索|零转化且有缺口返回无有限解|
|effective_snapshot|对已核证的截止日快照按自然人去重|字段勾选不证明资料真实；同人状态冲突报错，不自动选有利状态；非完整历史事件系统|
|workload|按技能看工作量和分配净工时|一个人的跨技能分配不得超其净小时；不自动把无对应技能的人替代审核岗|
|zero_event_upper|零事件下简单二项假设的单侧上界|不能证明食品安全，不解决非随机样本偏差|

每份JSON为model与data两层；字段示例见教学情景和测试文件。生产模型没有保存任何真实个人信息。

## 核查依据

20项测试覆盖质量平衡、超装、剔废/样品去重、缺值与零、无效得率、干实基、期中现金缺口、融资隔离、同日先后、线索反推、自然人重复/状态冲突、失效/员工排除、跨岗超配、技能瓶颈及零事件不确定性。测试结果见上一级内部核对目录。

测试只证明本工具在这些案例中的行为。旧Excel模型未在本轮重新验证，不能把本次结果移用到旧文件。

## 配套CSV

「关键证据与决定.csv」整理本轮最重要的输入、来源和未完成验证；「五款开发比较.csv」记录五个候选与独立验证项。没有填写企业报价、实际销量、用户身份或检验结果；不冒充执行台账。
