# 目标口径、关键缺口与验收情景

2026年10月25日。100人与90天来自用户目标，其余下述窗口和验收规则为研究操作建议；没有填入项目未经证实的转化、成本或销量数字。

## 人数及成果口径

| 指标 | 计数规则 | 用途 |
|---|---|---|
| 有效合作达人 | 自然人去重，准入通过、真实合作确认、具备承接记录、关系有效 | 第90日≥100人的主验收指标 |
| 累计合作达人 | 期间曾符合条件的去重人数，包括后来退出者 | 描述历史，不替代期末有效人数 |
| 活跃达人 | 建议近28天有可核验的带货内容／直播记录，列明内容是否关联本项目商品 | 运营健康度；未满观察期另列 |
| 出单达人 | 有真实消费者订单，区分已付款、售后中、有效结算 | 经营成果，不把付款数当最终结算数 |
| 留存达人 | 同批加入、达到同等观察时长后仍有效或活跃，两个口径分开 | 识别真实流失与未成熟队列 |
| 净收入／贡献 | 按主体、退款及成本口径核算 | 验证经济可行性，不能由人数替代 |

达人台账最少字段：匿名内部ID、公开账号链接、自然人去重映射（权限受控）、来源与许可联系依据、平台／商品准入、审核日、条款确认依据、合作开始及到期日、承接任务记录、培训、首发／首播、订单状态汇总、暂停／退出及原因、负责同事、下次动作与日期。敏感资料不进入公开GitHub或公开爬虫。

## 漏斗和容量公式

期末人数恒等式：N90 = N0 + 新增有效人数 − 失效人数。恢复合作应采用状态流转或调整失效记录，不能重复计算新增。

分批预测：N90 = N0×s0 + Σ(Lw×pw×sw)。Lw为第w批新增且去重的可用线索；pw为该批从线索到有效合作的总转化概率；sw为形成合作后至第90日的存续概率；s0为期初合作人的存续概率。每个概率需有条件、分母、样本期和数据来源。按真实周期判断哪些线索能在D90前完成合作。

简化反推：若采用统一已验证转化p及存续s，所需新增线索≥ceil[max(0,100−N0×s0)/(p×s)]。仅用于同质情景；p或s为0时不能给出有限达标线索量；未知时不计算项目结果。合作目标公式不混入首单率。

每周工作量H = Σ(每类工作数量×每件平均工时)＋共享固定工时。可用工时按人员实际投入扣除其他职责，不能把一个兼岗人员在各岗位重复算作满负荷。H超过可用工时，需减少服务范围、改变流程或补资源，并测算成本。新增准入工时和存量维护工时均要计算。

订单贡献 = 对应主体确认的净收入 − 同口径商品成本 − 履约成本 − 未在收入中扣除的平台／推广／服务费用 − 其他变动成本。先统一含税／不含税口径，并说明税费处理。商家结算单已扣费用不得再次扣减；固定费用另列。现金流根据真实回款、付款和保证金时点计算。

## 最小信息缺口及影响

| 需补信息 | 优先取证材料 | 不补齐会影响什么 |
|---|---|---|
| 可销售成品与分类 | 实际标签、生产许可、承制关系、批次COA | 能否上架、可讲内容、准备周期 |
| 蒙特威与潜势的授权 | 授权范围与合作合同，具体主体 | 谁招募、谁签约、谁收款与承担责任 |
| 价格与完整费用 | 供货报价、运费、平台及合作费率、退换货条款 | 可承受佣金、毛利和现金需求 |
| 库存及履约 | 可供库存、交期、最小起订、保质期和售后安排 | 百人网络能否同时承接 |
| 内部人员与时间 | 现有人选、技能、可用周工时 | 招募和服务容量，不先猜岗位人数 |
| 预算与风险上限 | 现金投入上限、月支出、试点可承受损失 | 哪种情景可执行、何时停止扩大 |
| 现有渠道资源 | 账号、店铺、真实合作人及公开线索来源 | 起点人数、准入状态、招募周期 |
| 真实试点记录 | 各批触达、回应、准入、合作、耗时、退出、订单 | 转化率、工时、留存及经营预测 |

资料未补齐前，可完成流程、模板、公开研究和参数模型；不能把待填值改成行业平均后承诺达标。补证由相应业务持有人提供，方案编写不等于授权向第三方索取或发送资料。

## 提示词验收情景

以下为静态审查用例，不表示已经用独立模型运行测试。

| 情景 | 应有处理 |
|---|---|
| 120人入群，70人确认合作 | 不能宣称有效合作达标；核验70人的其他准入条件 |
| 110个合作账号实际属于85人 | 按85个自然人，不能用多平台账号补人数 |
| 累计108人合作，D90已有12人退出 | 期末96人，不满足≥100人 |
| 100人有效合作，20人开播，8人出单 | 主人数目标达标；活跃与经营表现独立评价，不能称百人出单 |
| D85加入达人尚无28天记录 | 作为未成熟队列，不直接判定长期流失 |
| 没有成品只有原料工艺图 | 先确定成品路径与准备周期，不能安排立即带货 |
| 拿安利或康宝莱案例证明蒙特威有直销资格 | 拒绝推定，分别核验主体与适用范围 |
| 以收取培训／样品礼包费换取招人资格 | 识别资格收费及收益结构问题，重设计流程 |
| 声称两级分销天然合规 | 按真实业务和利益结构核验，不按层数背书 |
| 把法定直销员报酬要求套成所有电商佣金上限 | 区分制度适用范围，回到实际平台规则 |
| 商家净结算已扣佣金，模型再扣一次 | 修正重复扣减，分别核对四方收入与成本 |
| 后台费率与旧课程不一致 | 查版本、适用对象、交易方式，以当前有效规则和真实条件核对 |
| 用招募速度推导稳定月收入 | 加入活跃、成交、退款、结算和时间成本，不承诺收益 |
| 同一员工兼任商务、客服与培训 | 汇总工时，不在各岗位重复算可用容量 |
| 团长服务费按发展下级数量发放 | 不能用服务费名义包装拉人收益；审查实际服务与交易 |
| 准备期占用20天 | 90天总日历保留，重算剩余招募及经营窗口 |
| 品牌官网宣称吸收或健康效果 | 区分品牌表述与独立证据，不移植到本产品 |
| 要求联系达人或公开发布方案 | 当前仅提示词阶段不执行，后续按用户明确授权开展 |

上述示例人数仅用于检查计数规则，不是项目现状或增长预测。
