# 0. 总评

1. **最严重的问题是“未经证实的产品变更被写成已确认事实”。** 11月11日确认的“3+2口味、统一3003、约30g条包”，与V1的“A纯乳清＋B乳清CPP、六配方、十二规格”不是同一开发任务。“用户已确认CPP名称”目前缺少可追溯依据，必须撤回其确定性表述。

2. **产品范围变更、食品类别变更、原料采购扩展、包装规格扩展，被合并成一次默认授权。** 即使用户确实同意A/B两款，也不当然意味着同意采购WPI、开发单独WPI款、增加15g／罐装／大袋装，或同意A采用GB 11674、B采用固体饮料路径。

3. **V1没有建立3003产品所需的独立法规与标签分支。** 若沿用3+2，现有包装不能通过替换口味名称继续使用：主要展示面类别、适宜人群、每日或每餐食用量、营养标签依据和工厂许可条件均需重建。

4. **“供料代工必须完整混配＋灌装”没有成为制造准入关口。** “终端分装条件”“100%单一原料直接成为A款”的写法容易把原料换袋当成成品开发。原味款也必须提交真实、合法、可制造的完整工艺，不能通过增加无意义混合步骤或虚构辅料应付要求。

## 2.3 `01_品牌命名与商标推进.md`

### ① 主要问题

命名候选本身可以保留；问题集中在权属、商品范围与时间费用的表达。

- “新消费品牌归属由三方明确”弱化了营销公司自有品牌方向。
- 消费者访谈“同一价格”尚无价格依据，可能把任意价格植入命名测试。
- “先形成四套两线包装”容易把产品路线与品牌评价绑定。
- 费用算例正确，但三类申请只是算例，不是已经核定的申请组合。

### ② 冲突

## 2.5 `03_组织架构分工与招聘方案.md`

### ① 主要问题

## 4.3 比价口径

\[
每100g粉体价格=\frac{对应SKU价格}{该SKU净含量g}\times100
\]

\[
每25g蛋白质成本=
\frac{对应SKU可比到手价\times25}
{该SKU净含量g\times成品蛋白质质量分数}
\]

必须同时满足：

- 同一SKU、地区版本、规格及营养表；
- 明确税费、运费、优惠和赠品处理；
- 明确标价、建议价与实际结算价；
- 同组比较，不将保健食品、医疗营养与普通乳清混成排名；
- 不能用WPC80、WPI90原料等级代替成品蛋白值；
- 不把CPP、胶原或总蛋白各自的量互相替代。

现有41.32、55.14、85.60、57.00元／100g等，可保留为**V1记录的页面价格锚及其算术结果**，不升级为本日实时成交价、全国价格带或建议零售价。
