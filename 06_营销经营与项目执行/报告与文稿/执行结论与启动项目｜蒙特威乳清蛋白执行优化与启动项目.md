# 蒙特威乳清蛋白执行优化与启动项目

2026年10月28日｜内部执行版 V1｜适用对象：潜势项目负责人、蒙特威产品与经营接口。

当前优先级是把已有原料转化为「可验证的客户应用」和「可核算的首款成品」。本轮启动六项内部专项：资料版本统一、原料客户验证、30g条包开发、代工准入比价、经营合作与现金核算、五人团队与达人承接。六项均已形成办理成果；企业收件、实际客户接触、打样和经营结果仍需真实执行。

来源优先顺序：当前明确指示和可核对的用户原话 → 对应事项的有效企业证据 → 已锁定的内部方案参数 → 公开原始资料 → 历史分析与AI草稿。日期较新不能把提案升级为事实。

## 二 现在最值得改变的五件事

1. **把1吨作为询价与规模测算基准，分开决定小试、中试和量产。** 若按纯粉、98%得率、平均实灌30g演示，约32,666条。假设100人每人寄5条，只用500条，余32,166条；达人样品需求并不足以支撑整吨量产。先取得合格样品、真实正常价需求和可承受库存上限，再决定投料。不是把1吨从计划中删除。
2. **A线同步推进应用和报价准备。** 成品研发延误不应让原料客户工作停摆。先比较客户每公斤可用蛋白成本、换料验证和付款条件，避免只有「内蒙古产地」故事而没有采购理由。
3. **供应商按实际生产法人一行管理。** 衡美/吉美、天益/天利是关联线索，艾兰得与康比特是不同候选，不能共用一个报价格；一家公司可能既是原料潜客又是承制候选，建立两个商机和两套交易口径。
4. **70/30权益、出资、服务费与工资分别约定。** 保留合作方向；不要把团队管理能力直接写成可办理注册资本出资，也不能把工商股比自动等同实际可分配现金。
5. **把「研发通过」「可销售」「达人有效」「实际赚钱」分开验收。** 任一指标不能替代其余指标。所有新底稿采用现行G0—G5，不沿用旧G0—G4或B0已有成品试销路线。

图片材料补读另发现：《仙女蛋白粉避坑指南》把WPI说成唯一选择，并将WPC与致痘等直接关联，不能作为当前WPC80项目的培训定论或对外依据。该PPT曾因以图片为主而仅能抽取少量文字，本轮已补齐图片文字识别并核对关键画面。
