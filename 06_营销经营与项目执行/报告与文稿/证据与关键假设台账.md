## 五、需求验证记录模板

一条记录只对应一个实际客户、项目或消费场景。内部编号替代不必要的个人信息；未获授权不向公开研究服务上传客户资料。

| 字段 | 填写要求 |
|---|---|
| 对象及日期 | 客户类型、接触渠道、记录人、日期、信息使用范围 |
| 真实问题 | 最近实际购买／采购、使用场景、当前替代品及不满意点 |
| 决策权与程序 | 谁选料、测试、批准、采购、付款；不可只记录联系人头衔 |
| 产品条件 | 料号、规格、样品版本、验收方法、供应及付款要求 |
| 价格及费用 | 所见完整报价、规格、税运、优惠条件，是否实际付款 |
| 证据阶段 | 线索、有效需求、测试、报价、订单、交付、回款、复购分别勾选 |
| 反面信息 | 拒绝、替代方案、价格异议、停止测试、退款及原因 |
| 下一步 | 由谁补什么证据；预计日期由承担者确认 |
