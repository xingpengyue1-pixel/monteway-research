# 蒙特威乳清蛋白全国线上招商与推广综合方案

潜势咨询｜V3整体更正版｜2026年10月23日｜中国大陆市场内部决策与执行稿

本稿承接《乳清蛋白Ⅱ型产品综合营销方案》的资料研究，但按本轮用户更正重新确定经营对象和分工。「Ⅱ型」暂保留于历史项目名称，不作为蒙特威本次产品已经核实的技术分类或正式品名。本文替代V1、V2的经营主线；原研究、报告和纠错记录保留。

## 一、决策摘要

项目以**蒙特威科技研发生产的乳清蛋白原料，以及使用该原料生产包装的产品**为推广对象，采用用户提供的「奶源取自内蒙古大草原」项目口径，由**潜势咨询负责全国线上招商与推广**。上述项目分工已由用户明确；具体原料牌号、成品品牌、生产包装主体、供应能力及对外授权范围仍需用文件落实。（U02）

同时开展两条招商路径：**A线面向品牌方、食品企业的原料采购及定制/OEM合作；B线面向成品经销商、团长及线上分销渠道。**两线共用资料中心和内容制作能力，分别管理需求、报价、合同、回款、交付与复购。定制/OEM能力尚未确认时，A线先接收需求、组织技术评估，不承诺承制。（U03；策略推断）

推荐先做「资料可核验、样品可评价、交易条件可计算」的基础招商，再根据客户试样和真实销售结果升级技术差异化表达。近期的关键产出是两份可用招商资料包、两套客户筛选及跟进流程、供货与授权文件、三方经营测算。全国触达不等于立即铺设全国代理，也不等于所有平台同时投放。

|路线|当前判断|启动条件|取舍|
|---|---|---|---|
|A. 以现有产品及证据招商|主推荐；先把能够实际供货的产品讲清楚|实际产品档案、资质范围、供货价格、责任分工齐备|不依赖未证实的特殊功效和「Ⅱ型」溢价|
|B. 补齐差异化证据后升级|作为第二阶段|本牌号或本SKU的检测、应用对比、可追溯奶源等证据|优先验证客户关心的稳定性、适配性、交付与成本；人体效果另作专门证据审查|
|C. 调整规格、组合或定制开发|条件式备选|重复出现的客户需求，现有产品无法满足；供货方确认能力、成本与合法生产路径|优先在蒙特威原料及既定合作框架内解决，不把潜势自有品牌或寻找替代工厂作为默认任务|

未解决的关键项包括：原料究竟是何种规格、成品有哪些实际SKU、谁生产包装、谁签合同收款、潜势如何收费、样品及售后由谁承担。资料不齐期间可完成访谈提纲、内容草稿和招商工具；对外发出具体产品承诺、报价、政策前，须完成相应事实和权限核对。

## 二、产品事实与市场机会

### 1. 将原料、成品和服务分开管理

产品链按「内蒙古奶源—蒙特威原料研发生产—原料客户应用，或成品生产包装—渠道销售—消费者使用」建立档案。奶源所在地、原料产地、成品加工地分别记录，不能互相替代。

原料档案应载明完整名称、型号、类别、标准、蛋白与乳糖等规格、微生物及污染物控制、批次COA、包装、保质期和储运条件。成品档案另列品牌、完整品名、许可和生产包装主体、配料、营养表、规格、食用说明及售后。**原料的蛋白纯度不是成品的蛋白含量；每份粉重也不是每份蛋白摄入量。**

公开公司介绍和产品页面出现乳清业务，但页面标题与正文中的企业名称存在「内蒙古蒙特威生物科技有限公司／内蒙古蒙特威科技有限公司」差异；网页中的计划产能也不能作为现有可供货量。当前统一使用「蒙特威科技」项目简称，法律主体以执照、许可和实际合同一致性核验为准。产品页面的通用营养介绍不能证明本牌号的纯度、技术分级或特定效果。[公司介绍](https://www.mengteweisw.com/about.aspx?nid=1&typeid=1)、[乳清产品页](https://www.mengteweisw.com/prod_view.aspx?id=232&nid=3&typeid=67)（W15、W16；10月23日检索返回可读文本，直连正文未完整取得）。

天源照片只能证明所拍天源产品的可见标签信息，不能给本项目提供成品许可、配方、含量、规格或功效背书。尚无充分材料确认本次蒙特威产品的「Ⅱ型」含义，不把它解释为Ⅱ型胶原蛋白、分离乳清、乳清肽或人乳来源蛋白。（S01、S02、D06）

### 2. 市场机会以具体采购和销售问题验证

历史报告支持建立以下测试方向，尚不证明蒙特威的需求已经成立：原料客户是否需要新的合格供应来源、成分和应用表现是否满足要求、价格与交付是否可接受；成品渠道是否能以合理库存获得可持续销售、消费者是否理解产品并愿意付费。（N02、N06、N23、N24、N31、N40）

2022年乳清消费资料只用于设计场景访谈；美国蛋白调查不直接外推中国需求；乳业现金流报告只借鉴库存与回款方法；胶原和药物蛋白资料不用于本品功效或市场规模。没有以行业大盘增长推导本项目招商金额。

竞品研究随产品档案启动。A线直接竞品必须同原料类别、规格、检测口径、采购量和贸易条件；B线直接竞品必须同产品类别、目标场景与销售条件。其他蛋白来源属于需求替代品，成熟经销政策属于渠道参照品。当前缺少蒙特威规格和报价，不能得出「更便宜」「蛋白更高」「渠道利润更大」的数值结论。附件03给出可填写比较表及不可比较项。

## 四、定位与价值表达

内部定位为：**围绕蒙特威乳清蛋白原料与相关产品，建立面向全国原料应用客户和成品经营渠道的合作服务，由潜势咨询组织线上信息触达、需求筛选与成交协同。**

对外表达分两层：先让对方理解合作对象、产品和流程，再用已核实的奶源、规格、检测与履约证据支持选择。奶源故事承担来源说明，不承担人体功效证明。

|对象|重点信息|需要支持的证据|避免使用的捷径|
|---|---|---|---|
|原料采购与技术人员|规格是否适配、批次是否一致、应用评价与交货条件|规格书、COA、样品批号、试验记录、正式报价|用「内蒙古大草原」替代技术指标；用专利数量替代应用效果|
|定制品牌方|产品定义、承制能力、开发流程和责任边界|承制主体、能力与许可、打样及验收协议|「一站式全包」「任何配方都能做」等未确认承诺|
|成品渠道|适合谁、怎么讲、如何计算收益、售后怎样落地|SKU档案、交易条件、素材审核、履约售后规则|保证利润、保证销量、稳赚回本、压货换区域|
|终端消费者|是什么、含多少、如何食用、每次成本与购买条件|成品标签、营养表、适用说明和实际成交价|把原料资料、通用研究或体验包装为本品临床结果|

「内蒙古奶源」「蒙特威研发生产」「潜势咨询负责全国线上招商推广」目前分别依据用户说明和项目安排。正式外发时应附适用的来源材料、主体资料和授权文件；「全国独家总代」「唯一官方」没有当前依据。完整允许条件见附件03。

## 五、产品组合与招商定价

### A线：从真实原料规格建立供货目录

先按实际可供牌号列标准供货目录，不自行命名WPC80、WPI或特殊乳清。每项报价统一说明计价单位、含税情况、运费、包装、采购量、付款条件、有效期及可供交期。技术规格一致后比较每千克原料价格；需要比较每千克蛋白成本时，使用同基准检测值，说明干基与实物基差异、得率及加工成本。

样品、小批试用、批量采购三个层级是建议的交易流程，不是已经存在的SKU或价格政策。样品是否收费、运费及测试费用由双方书面确定。定制/OEM另外列研发、打样、包材、生产、检验和变更费用，不用原料单价代替成品总成本。

### B线：围绕已授权成品建立试销与补货组合

先列现有可售SKU，再设计「样品了解—小规模首单—依据净售出补货」的合作过程。试销数量由渠道需求、保质期、现金和履约条件决定。只有确认改包装的生产、标签、成本条件后，才研究试用装或组合装；旧稿25克、14袋、350克等不作为本项目既有规格。

招商政策须包含供货价、适用渠道、运费、开票、结算、退换与质量处理、临期责任、素材使用、促销支持及退出。阶梯价格应对应真实采购或服务差异，返利以可核对的交易条件结算。区域和渠道权益按实际履约能力商议，不预设排他或强制转售价格。

两线都不凭空设定起订量、保证金、代理费、返佣率及保底销售额。潜势的服务费和成交服务结算单独商议，不从历史AI稿的佣金比例直接继承。

## 六、渠道与成交路径

### 1. 先验证两条路径，再增加平台

建议以一套公开资料入口、一个主要内容渠道及一个可留存跟进的企业客户服务工具启动。若已有微信经营资源，视频号与合规企业微信承接可作为候选；若没有，先审查账号、人员与客户来源，再决定主阵地。抖音用于测试公开内容触达与预约意向，小红书用于成品理解和使用问题；货架电商承担具备资质的成品交易；行业渠道和线下业务协同用于技术试样和渠道履约。它们均是待资源核对的候选，不要求全部铺开。

平台招商内容、食品类别准入、广告资质、联系方式与站外引导、直播和交易规则需按实际账号与产品类别核对。历史检索未完整取得所有动态规则，因此本稿没有给出任何平台已准入、可直接导流或固定费率的结论。上线前将规则名称、链接、版本日期、账号类别、核对人和结论登记，未通过的动作改为平台允许的咨询或交易方式。

### 2. A线：需求进入技术流程

技术内容/行业触达 → 合规留资 → 确认应用、规格、采购阶段和时间 → 蒙特威技术评估 → 按授权寄样 → 客户应用评价 → 供货方正式报价 → 实际合同主体签约收款 → 验收交付 → 复购及年度供货评估。

潜势负责内容、线索、需求完整性、会议组织和跟进记录；供货方负责规格及产能确认、样品与技术答复、产品承诺、报价和履约。潜势未经授权不替技术负责人确认可用性，也不代收货款。没有明确测试反馈和采购节点的线索不进入确定销售预测。

### 3. B线：首单必须连接终端销售

招商内容/说明会 → 渠道类型与客群筛选 → 产品资料和合作条件说明 → 样品及经营核算 → 合同与首单 → 产品培训/售后协同 → 跟踪终端净售出、库存及投诉 → 小步补货 → 根据连续履约结果扩大合作。

签约、首单付款、有效开售、终端净售出、复购分别计数；渠道进货不等于消费者需求。获客与培训投入优先给愿意提供经营反馈、能处理售后且库存可控的渠道。

### 4. 双路径客户与归属管理

同一企业只有一个主体编号，A、B机会可分别建立；共享一次基础资质确认。明确客户来源时间、跟进责任、既有客户与新客认定、重复线索处理、成交服务归属及争议处理。不得把同一交易分别记入两线新增客户或重复计提成功费用。表单仅收集必要业务信息，内部客户材料不发到公开爬虫。

## 七、内容与销售支持

内容围绕六个问题组织：产品是什么；来源如何核验；规格与标签怎么看；怎样试样或试销；钱和责任怎样算；合作后如何交付。先有证据包，再制作对应素材。

原料招商资料包顺序为「企业与产品身份—规格和批次—应用条件—试样流程—供应与报价—技术沟通方式」。成品招商资料包顺序为「实际SKU—适配客群—产品表达—经营测算—试销与补货—售后与素材支持」。证据缺项应显示缺项，不用工厂形象片填补规格和许可空白。

直播或线上说明会按客户类型分场。A场重点解答规格、检测、应用、采购周期和定制可行性；B场重点解答产品、首单、实销、成本和售后。不把二者混成泛泛的「全国招代理」直播。招商页面设置两个明确入口，避免原料采购进入消费者详情页。

首月建议制作12个短视频选题、4篇图文和两类说明会脚本；这是排期假设，可按团队产能缩减。附件05提供可编辑样稿、客服回复及详情页框架。涉及奶源证明、具体规格、价格与授权的占位内容保持内部状态，填入已核实资料后再审稿。

## 八、经营测算与投入判断

经营评价使用三张独立损益表：**供货方货品账、渠道方经营账、潜势咨询服务账**。合同金额、回款、货品GMV、收入与利润分别呈现。潜势的收入来自约定服务及可确认的成交服务结算，不直接等于招商货值。

供货方按原料或成品净销售收入减生产/采购及包装成本计算毛利，再扣履约、佣金、投放、售后等得到营销后贡献；渠道方按退款后净收入减进货、履约、平台、内容投放与售后测算。潜势按已履约可确认服务收入减交付、线索、样品协调、差旅和外包等费用计算贡献，再扣固定成本。详见附件04口径和公式。

启动预算应覆盖资料与技术支撑、内容生产、客户管理、样品及测试、必要推广、合同和售后；金额、负责人和付款主体逐项待填。未验证复购前不以未来佣金或客户长期价值补齐首单亏损。A线长采购周期和B线退款观察期不同，分别设成熟观察窗口，不用尚未转化的当周线索判断最终获客成本。

建议只有在相应路径出现可复核交易贡献、交付稳定、投诉可处理且现金可承受时，才增加获客投入。发现技术不适配、渠道首单只能靠补贴、潜势服务收入覆盖不了交付成本时，分别调整产品/目标客户、商业条件或服务边界。调整后仍不能成立则停止该路径新增投入，保留另一条已验证路径。

## 九、90天分阶段执行

90天为规划周期，不是成交或回款承诺。A线可能在周期末仍处客户试验阶段，不能为完成报表提前认定成交。

|阶段|共同任务|A线交付|B线交付|继续条件|
|---|---|---|---|---|
|第1—15天：资料与规则|产品档案、授权分工、报价口径、账号资源与费用预算|规格书、试样流程、需求表、承制能力边界|真实SKU、政策底稿、售后流程、渠道需求表|产品、主体、责任能够明确；未满足的环节暂停外发承诺|
|第16—30天：小范围验证|完成内容与访谈、记录异议及投入|取得有技术背景的需求反馈，安排获授权试样|选择具备客群的小规模试销候选|出现真实应用/经营需求，能完成成本核算；数量目标由资源确认后填入|
|第31—60天：验证转化|逐线复盘来源质量、响应、成本和丢单|试样结果、合格规格、正式报价及采购决策进度|首单、实际开售、终端净售出、退款与库存|技术或销售反馈可复核；服务与供货履约稳定|
|第61—90天：条件式扩大|重算三方贡献与现金，决定平台和人力增加|成熟项目采购/复购或明确下一验证节点|成熟渠道补货与经营贡献|只放大已通过条件的路径；未通过则缩小、调整或暂停|

主策略的依据、资源和调整条件统一如下；所有转化目标和样本量目前均待实测，不设无依据的百万招商指标。

## 十、风险与调整机制

产品规格无法确认时，停止具体性能招商；奶源链条不足时，暂停将来源故事扩展为品质优越性；授权不清时，完成内部材料但不发布独家或代收款承诺。发现严重质量问题或不当功效表述，先处理受影响批次或素材，再恢复推广。

价格异议须拆分为产品价值、交易条件、客户不匹配和渠道费用，不能只靠增加返佣解决。B线进货增长但终端净售出弱时，降低补货并查库存；A线大量索样无评价时，提高需求筛选质量；潜势收入没有随工作量兑现时，重订阶段交付和结算边界。

每两周进行一次经营复盘属于建议节奏。采用成熟样本和同口径数据对比；连续两个观察批次未改善可作为复审触发条件，这是管理假设，不是统计显著性结论。复盘必须作出继续、调整、暂停之一，并列清下一步负责人和验证日期。
