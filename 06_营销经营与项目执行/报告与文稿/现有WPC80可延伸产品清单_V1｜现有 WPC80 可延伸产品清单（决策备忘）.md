## 0. 一句话结论

在**现有／拟议 WPC80 为主原料、且不另立 WPI／酶解／CaHMB／FSMP／蓝帽料线**的前提下：**优先可做**的是「同料运动营养／普通冲饮粉」路径下的**独立条包首款（约30g）及其同配方轻调味变体、同SKU女性便携场景扩展**，以及 **A 线把 WPC80 作为配料卖给食品厂做冲饮／乳饮／烘焙验证**；**可做但延后**的是罐装／家庭装、不同克重条包、蛋白棒／曲奇、烘焙预混包、酸奶／乳饮应用深度开发；**不宜用现有料硬做**的是术后特医、肌少酶解＋CaHMB、蓝帽、女性 WPI 次抛另立 SKU、清澈酸性即饮／高热稳 RTD（通常需专用热稳牌号或 WPI）——与 05 号扩围研判一致，首批仍锁 **1 个可售 SKU**。

| 分层 | 含义 | 代表项 |
|---|---|---|
| **优先可做**（仍以 WPC80） | 与首款同料同许可路径、增量主要在包材／口味／场景话术或 A 线试样 | ≈30g 独立条包首款；同配方轻调味；同 SKU 女性便携场景；A 线冲饮／乳饮／烘焙试样 |
| **可做但延后** | 技术上常见用 WPC，但新增包材／工艺／MOQ／许可明细或客户验证，不宜与首吨抢资源 | 罐装／家庭装；10–20g／其他克重条包；蛋白棒／曲奇；烘焙预混；酸奶／乳饮深度配方；固体饮料备选路径 |
| **不宜用现有料硬做** | 通常需改料（WPI／酶解／特医／蓝帽／专用热稳）或声称越界 | 术后 FSMP；肌少酶解＋CaHMB；蓝帽；女性 WPI／0 乳糖另立 SKU；清澈酸性 RTD；宣称诊疗营养 |

## 3. A 线 vs B 线（同一吨原料的两种用法）

| 维度 | **A 线：原料应用拓展** | **B 线：自有品牌成品** |
|---|---|---|
| 交易本质 | 卖／试样 **WPC80 粉**给食品厂、饮料／乳品／烘焙／运动营养代工厂 | 委托加工后销售 **蒙特威（或授权）品牌成品** |
| 典型延伸 | 客户冲饮粉换料对照；酸奶／含乳饮料强化；烘焙／棒类质构试验；预混料供应 | 30g 条包；未来罐装；未来棒／曲奇（若立项） |
| 谁做配方验证 | **客户**研发＋我方提供规格／COA／应用卡 | **我方＋承制方**按 PRD-B01 |
| 许可重心 | 原料合格证明、供货合同；一般不占用我方成品 SC | 承制方 SC 覆盖拟类别；标签／广告责任主体 |
| 与达人目标 | **不计入** B 线有效达人 | 计入（成品可售后） |
| 当前建议 | **与 B 线并行推进**，不因条包延误停摆 | **首批锁 1 个 SKU**（≈30g 条包） |

> 深度调研已区分：若目标是「把 WPC80 卖给西子等供其品牌使用」，应走 **原料供货（模式 D）**，不套我方成品代工利润模型。

## 6. 待企业输入（影响「能不能做」）

| 字段 | 主要影响哪些延伸项 |
|---|---|
| **牌号、制造方、批次、COA**（蛋白干基／实物基、方法、水分、脂肪、灰分、微生物） | 全部 B 线标签蛋白；运动营养脂肪／蛋白是否达标；A 线客户准入 |
| **速溶性／润湿分散（是否速溶型／加卵磷脂等）** | 冲饮条包／罐装体验；A 线 RTM；不达标则须工艺或改牌号 |
| **乳糖实测** | 能否碰「乳糖不耐／0 乳糖」话术（通常不能）；女性高端叙事边界 |
| **脂肪** | GB 24154 补充蛋白质类脂肪上限（公开口径需与现行标准及成品实测核对）；高脂时运动营养路径风险 |
| **是否热稳型／棒用功能性牌号** | RTD、高温乳饮、蛋白棒是否值得开专项；否则标「现有料不足」 |
| **承制 SC 明细是否含运动营养／特膳粉剂、条包灌装、固体饮料** | 类别终裁；固体饮料备选是否可走 |
| **是否接受分装／必须完整生产**（地方审查方案） | 仅灌装模式是否可行 |
| **可供库存、剩余保质期、到厂成本** | A／B 分流吨数；棒／罐装是否另开料 |
| **是否另有 WPI／水解乳清库存或采购授权** | 第 5 节路线是否存在原料前提（有也不进首批） |
| **品牌／委托／销售主体** | 标签责任人；A 线签约主体 |

## 7. 公开应用常识摘要（检索日 2026-10-28，非本品结论）

- **中国零售常见终形态**：运动营养／蛋白粉的**罐装与条包／袋装**；蛋白棒等固体零食；原料侧进入烘焙、饮料、酸奶等（偏 A 线）。电商可见大量「WPC80 浓缩速溶」原粉与成品粉剂形态（二手市场观察，非蒙特威上市证据）。
- **运动营养 vs 固体饮料**：运动营养补充蛋白质类属特殊膳食用食品（GB 24154 体系），标签与生产许可要求不同于普通**固体饮料**；固体饮料不得明示／暗示保健功能。类别须企业终裁＋承制 SC 匹配（**待核**）。
- **WPC 公开应用举例**：冲调蛋白粉、营养棒、酸奶／含乳饮料／乳甜点、部分饮料强化等（如 NZMP 浓缩乳清蛋白公开应用页）。**即饮高蛋白／热加工**常单独强调热稳或改用 WPI——故 RTD 不默认可用「现有未核热稳的 WPC80」硬做。
- **通常需改料的信号**：清澈酸性饮料→多 WPI；术后特医→FSMP＋专用配方；宣称极低乳糖／WPI→须 isolate；酶解吸收卖点→水解乳清；抗肌少 HMB 叙事→另复配／可能蓝帽。
