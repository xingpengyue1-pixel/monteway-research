## A 营销公司设立方案

建议新设有限责任公司，承接自有品牌、渠道资产、销售与客户服务。**独立设立应落实为独立账户、合同、账簿、库存和决策授权**；关联方供料、研发、人员支持及资金往来均须签约、计价、对账。

品牌自有不等于营销公司必须立即承担生产委托方职责。委托主体应根据食品经营资质、质量监督能力和三种合作情景确定，不能只根据商标归属决定。

### 1. 三种股权情景分别安排

| 事项 | 情景A：蒙特威约70%、潜势团队约30% | 情景B：团队组织股权、蒙特威不控股或少量持股 | 情景C：潜势咨询、段宜宗、蒙特威三方 |
|---|---|---|---|
| 适配逻辑 | 蒙特威承担主要资本与供应投入，团队负责经营 | 团队承担品牌经营风险，蒙特威主要作为供应与技术合作方 | 三方分别投入资金、经营能力或产业资源 |
| 设立前必须明确 | “潜势团队”实际持股主体；30%的出资来源、取得条件 | 团队内部持股结构；蒙特威是否持股及供应保障 | 段宜宗的身份、出资、职责，与潜势咨询是否重叠 |
| 出资建议 | 货币出资与团队激励分别约定，不能把未来劳务直接当作已实缴资本 | 团队资本金与蒙特威授信分别管理，不能默认供应商无限垫资 | 先列三方投入清单，再谈比例；资源承诺须可验收 |
| 委托生产安排 | 营销公司具备能力后可任委托方；蒙特威承担约定的技术支持 | 优先评估蒙特威组织研发与委托生产、营销公司限额采购成品 | 依据实际能力确定，不能按股东人数分摊法定责任 |
| 核心保护 | 少数股东防止关联采购高价、服务中断及经营权被随意收回 | 防止断供、供应商绕开渠道及营销公司过度赊购 | 防止职责重复收费、两方一致控制第三方及长期僵局 |
| 退出重点 | 团队离职、未完成约定投入、控制权变化的处理 | 终止供货后商标、库存、售后与客户资产如何保全 | 股权转让、优先购买、失能退出与僵局解决 |

三种情景不预设优先级。注册资本应由履约能力和资金计划倒推，并核实认缴期限要求；不得为展示实力认缴明显无法履行的金额。

团队激励可评估附条件股权转让、增资或其他合法安排，明确成熟条件、离职处理、回购主体、价格机制及税费。不能仅写“分期成熟”，却不设计可执行文件。

### 2. 治理、否决权与财务共管

| 层级 | 建议安排 |
|---|---|
| 股东会 | 审议资本变动、股权转让、重大融资、利润分配、清算等保留事项 |
| 董事会或一名董事 | 股东较少、业务简单时可评估一名董事；三方合作或利益差异明显时，董事会更便于形成制衡。具体结构依现行公司制度核验 |
| 经营负责人 | 在批准预算和授权内负责日常业务，承担阶段经营结果责任 |
| 质量负责人 | 对产品安全、检测、生产版本和批次放行拥有独立停止权；销售负责人不得越权放行 |
| 监督机制 | 依法确定监督安排，保证股东取得财务、关联交易和重大风险信息 |

关键事项否决范围应窄而明确，建议包括：品牌及核心知识产权处置、关联交易、对外担保、超预算借款、改变委托生产主体、超限赊销、重大质量事件处置原则。否决权须在章程、协议和授权表中衔接，由法务确认效力，不能笼统约定“任何事项双方同意”。

财务共管实行申请、审核、付款、对账分离；公章、财务章、银行权限避免由一人全部控制。双方或三方均可查阅月报、银行流水和关联往来。设置争议升级及替代审批机制，避免双签制度导致工资、税费或召回支出停摆。

### 3. 资金与首期额度

**60万元目前只是情景B、C出现的规划口径，不是已批准投资，也不当然适用于情景A。**

| 方式 | 使用原则 |
|---|---|
| 注资 | 用于长期经营基础和必要风险资本，不承诺固定回报 |
| 股东借款 | 明确利率、期限、用途、偿还顺序及税务处理；不得使公司刚上市就承担不可承受的还款压力 |
| 供应授信 | 与股东借款分别核算，明确货权、账期、信用上限及停供条件 |
| 阶段拨款 | 先支持资料核验与研发，再批准包材和试产，上市验证后才扩大备货与推广 |

首期预算须覆盖人员、研发检测、包材、试产、渠道保证金、仓配，以及退款、召回和退出储备。应编制滚动现金表，计入未付合同承诺；可用预算不能只看银行余额。

服务费、人员工资、销售佣金和股东分红须分别确定计费依据。启动期利润分成应先明确法律及财税性质；**股东分红以依法可分配利润及有效决议为基础**，不能到D90自动转换。

### 4. 合规与资产边界

| 事项 | 落地要求 |
|---|---|
| 食品经营 | 按实际业务确认仅销售预包装食品备案或其他许可要求，并核实网络经营、仓储、渠道类目条件；营业执照不能替代食品经营合规 |
| 商标与品牌 | 营销公司持有商标申请、设计成果及品牌账号；注册类别按具体商品与服务确定，不机械照搬类别清单。检索不等于获准注册 |
| 委托生产 | 明确委托方、受托方、品牌方、原料供应方和销售方。营销公司任委托方时，须具备供应商审核、合同管理、生产监督、追溯和召回能力 |
| 质量责任 | 内部约定蒙特威负责研发或放行，不能免除营销公司作为委托方或销售者的法定义务；第三方检测不能替代持续监督 |
| 广告审查 | 区分法定广告审查与企业内部审核，不把普通运动营养食品一律写成需要广告行政审批；适用性待法务核验 |
| 发布管理 | 标签、详情页、直播、达人、客服共用受控事实库；保存证据、审核版本、发布日期和撤稿记录 |
| 过渡签约 | 公司成立前由明确的现有主体依法签约；成立后涉及合同、商标、库存等转移时，办理必要承接和相对方同意 |

## B D1–D180运营规划

D1为正式授权启动日。**日历用于管理进度，证据用于决定能否进入下一阶段。** 产品未放行时仍可完成开发、渠道研究和履约准备，但不得以经营目标倒逼销售。

## C 首期产品开发详细建议

### 1. SKU与配方方向

维持已确认的**第一波原味、可可、椰子；第二波香草、咖啡，约30g独立条包**，待董事长终审。五款以运动营养食品·补充蛋白质类为目标，最终须由完整配方、许可范围和产品检测证明适配。

| SKU | 配方方向 | 首要验证 |
|---|---|---|
| 原味 | WPC原料为主；仅按需要加入合规工艺辅料，完整混配灌装 | 乳味、腥味、泡沫、分散性、脂肪与乳糖；不默认“纯粉更好喝” |
| 可可 | WPC＋真实可可原料；甜度、苦涩与香气分别试配 | 蛋白稀释、沉淀、颜色、可可原料污染风险；香精使用与图文一致 |
| 椰子 | WPC＋真椰浆粉，按脂肪预算降量 | 脂肪裕量、真实椰味、载体、氧化和稳定性 |
| 香草 | 明确使用香草原料、提取物或合规香精的具体路线 | 与原味区分度；不得用香草荚图案暗示不存在的原料 |
| 咖啡 | 明确咖啡粉、提取物或其他风味来源 | 总咖啡因、均匀性、苦味、沉淀及标签提示适用要求 |

“WPC80”只是工作名称。必须取得食品身份、生产商、批次COA、蛋白计量基准及检测方法、脂肪、水分、乳糖、微生物、储存运输和剩余保质期资料，不能把“80”直接当作每批湿基蛋白实测值。

### 2. 椰子款先做可行性计算

定义基粉、椰浆粉及其他配料质量占比分别为 \(w,c,a_i\)，各自脂肪含量为 \(F_w,F_c,F_i\)，则估算：

**成品脂肪＝\(wF_w+cF_c+\sum a_iF_i\)**，且全部配料占比合计为1。

若增加椰浆粉时等量替换WPC，须同时计算被替换的WPC脂肪和蛋白，不能只叠加椰浆粉脂肪。模型应采用原料规格上限或合理不利情景，并为批次波动、检测误差留裕量。

具体梯度待COA与现行标准核验后确定，不预先锁死3%、5%、7%、9%。若基粉自身已接近脂肪上限，降低椰浆粉也未必形成可生产方案。

处理顺序为：降低用量→核验低脂真椰浆粉及载体→优化允许的配方工艺→再验证。仍不通过则提交暂停或延后决定，**不得自动改固体饮料，也不得未经批准改用其他蛋白体系**。

### 3. 工艺与承制选择

| 维度 | 询价及审核要求 |
|---|---|
| 许可 | 核验有效生产许可证、品种明细、生产地址和拟产品适配范围；不能只看“3003”代码 |
| 完整混配 | 提供投料、筛分、预混、主混、异物控制、灌装和清线方案，确认非单纯分装 |
| 原味工艺 | 即使配料简单，也须确认实际工艺可实施，不为规避分装而虚增无必要配料 |
| 均匀性 | 小用量配料的预混与取样验证；咖啡因、甜味剂等关注局部浓度 |
| 速溶能力 | 区分原料已有速溶性、干混改善与团聚处理能力，不能承诺干混必然解决结团 |
| 低水分卫生 | 控制粉尘、环境和清洁；无杀菌步骤时重点审查来料及生产污染风险 |
| 商务 | 拆分研发、加工、包材、损耗、换线、检测、运输和税费；写清每口味MOQ及剩余包材归属 |
| 连续供应 | 核实排产、异常重做、追溯、留样、变更通知及备选转厂条件 |

打样配方、工艺参数、检测数据及设计文件的权属和使用权应明确，避免更换工厂后必须重新购买全部开发成果。

### 4. 检测与放行

| 层级 | 项目与目的 |
|---|---|
| 原料及辅料 | 身份、规格、蛋白、脂肪、水分、乳糖及风险项目；椰浆粉复合配料与载体；可可、咖啡原料专项风险 |
| 配方定型 | 按适用标准核验全部必要指标，包括分类条件、营养组成及相关比例；不能只检测蛋白和脂肪 |
| 安全项目 | 按类别及原料风险确定微生物、致病菌、污染物、真菌毒素和添加剂项目，不泛称“全项检测” |
| 使用性能 | 不同水温、水量、摇杯或搅拌条件下的分散、泡沫、沉淀及口感 |
| 包装与计量 | 食品接触材料符合性、封口强度、泄漏、夹粉、净含量、运输和易撕性 |
| 稳定性 | 实际包装条件下营养、微生物、结块、风味、氧化及封口变化；椰子单列 |
| 生产批次 | 按批准计划实施出厂检验和必要复核，留样并核对配方、包材和标签版本 |

实验室小样用于筛选，试产用于验证规模化。**实验室合格不能直接代表生产批次合格。** 保质期应有适用证据，不能照抄原料或同类产品；加速试验结论须说明适用边界。

### 5. 包装、标签与定价

建议先建立统一条包、单口味盒和必要组合装的信息体系。三味体验盒优先比较简洁共用结构，复杂翻盖、内托礼盒待需求和现金验证后决定。

| 项目 | 要求 |
|---|---|
| 产品名称 | 准确说明粉末冲调属性；“乳清蛋白条”可能被理解为蛋白棒，须审查 |
| 标签版本 | 按生产、上市时点建立适用标准及过渡清单；印刷前核验，不照搬15号方案的日期 |
| 营养数据 | 根据检测、工艺波动、允许误差和标示规则确定，不能照抄一次检测小数 |
| 过敏原 | 乳及其他实际存在或可能交叉接触成分如实评估；椰子分类核验，不能笼统按坚果处理 |
| 强调配料 | 真椰浆粉、可可等文字与图案须对应实际配料，依法评估定量标示 |
| 咖啡因 | 检测用于风险与食用建议评估；法定披露及警示依据另行确认 |
| 单条销售 | 若可能拆零、派样或达人转赠，应按相应使用情形审查内袋信息，不能默认免费样品无需完整管理 |

定价采用“成本底线＋渠道经济模型＋真实付费验证”：

- 先核算每条、每盒完全成本，含原料、加工、损耗、包材、检测分摊、仓配和税费。
- 按渠道扣除平台费用、达人佣金、服务费、优惠承担、运费补贴、退款及售后。
- 用不同成交价与获客成本情景计算订单贡献和现金回收，并与竞品同规格、同渠道口径比较。
- 以真实付费结果确认接受度；不沿用未经成本验证的历史概念价。

第二波上市须同时满足技术放行、资金可覆盖、第一波观察数据可解释；不能只凭某一周期贡献为正就扩产。

## D 风险与反对意见

15号方案具备任务框架，但尚不足以作为出资、印刷或批量生产依据。

| 漏洞或矛盾 | 具体问题 | 修正建议 |
|---|---|---|
| 股权冲突仍以A为基线 | 后文财务委派、共管和投入承担已按A展开，B、C无法只改比例沿用 | 三套权责、合同及资金安排分别设计 |
| “母公司”称谓提前确定 | B中蒙特威可能只是供应商，C也未必控股 | 未终裁前统一称蒙特威或拟出资方 |
| 先设立后验证的成本未评估 | 资料同时存在“先验证后设立”的意见，却未比较五人全职及公司固定成本 | 给出设立与人员分期到岗方案 |
| 60万元无现金压力检验 | 人员、研发、多口味包材、库存、推广并列，未证明额度足够 | 先做现金压力表，区分保证金、支出与承诺 |
| 委托主体责任悬空 | 建议营销公司任委托方，却把研发质量全部交给蒙特威 | 补质量协议、监督岗位和追溯召回能力 |

| 法规日期未经证明 | 新规名称、实施日和标准过渡期被直接写入排期 | 建立原文核验清单，核验前不作确定结论 |
| SC代码等同承制能力 | 有相应代码仍可能缺少来料、完整混配、条包能力 | 许可、工艺、设备、人员和实际能力分别审查 |

| 椰子梯度缺少基粉前置 | 既无COA，又预设比例和“预计接近上限” | 先计算可行域，再选梯度 |
| 克重调整无助浓度合规 | 从30g增至32g不会降低每100g脂肪 | 通过配方调整解决，克重另按体验及计量确定 |
| 椰子失败预案违反确认 | 仍保留转0606选项 | 删除自动改类，改为重配或提交延期决策 |
| 原味“完整混配”路径未明 | 可能只有单一原料，工艺与禁止分装要求如何一致未解决 | 承制前书面确认真实工艺，不做形式混配 |
| 稳定性启动偏晚 | W10才启动，却拟W12试产，保质期依据未交代 | 提前规划证据，不能靠短期观察直接确定长期保质期 |
| 标签样品代表性不足 | 小样检测即支持标签冻结，未交代规模波动 | 增加试产确认与变更控制 |
| 包材下单规则不可执行 | “不超过现金与可消化量较小值”可能低于MOQ | 明确低于MOQ时换方案、延期或停止 |
| 再次引入1吨假设 | 旧询价基准不代表实际可供或首批必须用量 | 重新核实批次、数量和各口味生产批量 |

| 人数管理投入过重 | 独立复核和去重台账占用资源，却未证明经营价值 | 保留必要去重，将重点放在内容及订单归因 |
| 岗位过载 | P2兼原料商务和五款开发，P4兼达人、客服、履约 | 按工时和关键路径重新分配 |
| 运营人群外扩 | 办公、下午茶、福利礼赠可能淡化运动营养适用边界 | 场景表达须与适用人群和标签一致 |
| 文案规则过度泛化 | 把某些字、咖啡提神表述一律视为法定禁用，混淆内部纪律与法律禁止 | 保持项目从严规则，同时标明规则来源 |

| 组合装低估复杂度 | 增加装盒、批次对应、标签、库存与退货处理 | 单独核算体验盒经济性及履约难度 |

| 周期缺乏支撑 | 2–4月、4–8月未附承制方排期与前置条件证明 | 用正式回件排期，所有日期保留条件 |

还应补充：产品责任保险评估、严重客诉升级、停发与召回权限、退货隔离、平台封禁应对、客户数据及达人联系方式权限、合作终止后的库存和售后承担。上述事项可能直接决定一次质量或经营异常能否被控制。

## E 需拍板问题

以下由有权股东或拟股东决定，董事长终审不能替代其他投资主体的有效同意。

| 问题 | 选项 | 我的倾向及理由 |
|---|---|---|
| 1. 最终采用哪种合作情景？ | A约70/30；B团队控股；C三方 | **不替用户取舍**。先分别确认投入、风险、经营权和退出，再确定比例 |
| 2. 何时完成公司设立？ | 立即设立；先完成关键验证再设立；限额筹备与设立并行 | 倾向限额筹备并行，前提是股东和基本责任已明确，避免长期以临时主体运营 |
