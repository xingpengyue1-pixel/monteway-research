## 三、先完成技术判断，再确定产品方向

把三张工艺图整理为「工序—材料原文—可判断事项—不能推断事项—需取得的实测或记录」矩阵。

当前截图记载的核心链条为：原料验收 → 净乳及预杀菌 → 脱脂 → 盐酸点酸至pH 4.6—4.8并分离酪蛋白 → 乳清液分离与膜过滤 → 二级超滤加水提纯及浓缩 → 氢氧化钠调节至pH 6.5—7.5 → 均质 → 杀菌 → 喷雾干燥 → 包装入库。截图还记载预杀菌80±5℃、15秒，均质50—68℃及16—22MPa，后段杀菌70—85℃、16—20秒，喷雾干燥进风155—165℃、出风70—80℃。这些是文件记载参数，不是实测运行记录或拟议新生产指令。

必须处理以下技术问题：

- 从可见流程看，优先核查酸沉淀酪蛋白后回收乳清的路线及其实际生产对应关系。不能仅因鲜奶起点和存在膜过滤，就认定是Native Whey、CFM、WPI90、水解乳清或「全程低温」。出现酸碱调节，也不能直接认定采用离子交换树脂工艺。
- 分清总蛋白含量、蛋白组分、天然构象、回收率、特定生物活性和人体效果。变性不直接等于营养价值消失；检测到某组分不等于其功能完整保留。没有本产品检测，不输出「全部失活」「活性保留90%」等结论。
- 喷雾干燥进／出风温度不能直接当作粉体实际温度；应索取物料热历程、停留时间和相应检测。不得为所谓保活而建议擅自降低杀菌强度。
- 截图「1nm」保留原文，核对膜型号、截留分子量、操作条件和实际分离效果；不得静默改成另一单位。浓缩液固含量18%—24%不等于蛋白纯度；脱脂物料脂肪≤0.05%不等于成品零脂；成品水分≤6.0%是截图要求，不是本批次实测值。
- 酸碱调整后将钠、氯离子／灰分、乳糖、风味和应用性能列入验证；不能据此断言产品高钠、有害或品质差。
- 将GB 11674等截图标准清单视为检索入口，核对完整标准号、年代号、现行状态和适用产品；附录列标准不等于企业获得许可，也不证明产品符合全部要求。

形成原料事实卡：实际生产主体及许可范围、牌号、原料来源、检测方法与干基／实物基、蛋白／水分／灰分／乳糖／脂肪／钠、必要安全指标、氨基酸与目标组分、溶解和热稳定性、批间一致性、规格、储运、保质期依据、MOQ、可供量、交期和有效报价。证据不足时给出分层检测计划：先做决定产品身份与安全的必要项目，再做支撑选定差异化卖点的项目，避免无目的地扩大检测费用。

## 四、产品开发方案的具体要求

### 1. 比较开发路线并提出取舍

至少比较下列候选方向，允许依据材料排除或合并；每条说明需求证据、技术适配、产品类别、成本与渠道条件、验证难度和当前决策。评分仅作内部建议，权重与依据公开；关键资料缺失时不伪造精确排名。

|候选方向|必须回答的问题|
|---|---|
|A线标准化原料供货及应用方案|本牌号最适合哪些食品应用？替换既有原料的质量、得率、供应与总成本价值是否成立？|
|日常营养补充基础成品|谁有明确购买需求？原味或少量调味的真实口感、价格及每份蛋白量能否支撑复购？|
|运动营养成品|实际原料、配方、适用人群、生产许可及标准能否同时满足？不能仅为了营销便利选择类别。|
|女性便携条袋装|购买理由是便携、口味、控量还是营养组成？是否愿为包装与服务支付价差？不能默认减脂、美容或不长痘效果。|
|一般中老年日常补充产品|可否在普通食品适用边界内满足真实生活场景？不能把竞品的术后／肌少症定位直接移植。|
|特医、保健食品或强调特定活性组分的路线|单独评估准入、研发证据、资源与周期；未具备条件则列中长期研究，不包装为近期上市捷径。|

最终建议一个优先验证方向和一个备选方向；资源不足时不要求多SKU同时开发。原料供货、成品销售、客户定制可分阶段实施，不把所有机会写成同一款产品。

### 2. 为入选方向编制产品需求书

每款产品填写：目标用户及排除范围、消费场景、待解决问题、真实食品类别与拟用名称、原料组成与配方逻辑、营养设计目标、单份净重与蛋白量、包装规格、风味、冲调体验、储存及保质期验证、目标到货成本、拟议售价逻辑、量产主体、检测验收、标签字段、开发难点和替代路线。

所有数值区分「现有实测」「设计目标」「待取得」；设计目标须说明需求和技术依据。不得沿用旧稿中的5g／20mL、WPC80／WPI90比例、乳铁蛋白／IgG数值、保质期24个月、日食用上限等作为已确认参数。复配成分按实际类别逐项查用途、用量、食用限制和标签条件，不为堆砌卖点而叠加。

比较大包装、条袋装与样品装时，同时考虑每份营养量、包材分摊、充填损耗、冲调便利、开封体验和渠道成本。小包装溢价必须在可比的同品牌／同配方／同口味／同一时点价格基础上分析，不能把跨品牌价格差全部归因于便携。

### 3. 建立研发和量产阶段关口

按「资料与类别确认 → 概念／应用筛选 → 实验室打样 → 小试与感官／使用测试 → 中试与包材验证 → 稳定性及货架期验证 → 量产放行 → 小规模商业验证」展开。

每阶段明确输入、操作责任、样品批次与对照、输出记录、预算项目、建议周期、通过条件、失败处理和下一阶段依赖。安全与法规阈值引用现行依据；感官、商业、成本阈值说明是拟议内部标准，不能伪称行业法定数值。检验、稳定性和货架期尚未完成时不能声称产品已验证，不能用90天商业排期压缩必要试验。

样品验证至少覆盖实际需求所需的蛋白与乳糖等关键指标、溶解／结团／泡沫／风味、温度与配伍条件、包材密封及吸湿、批次一致性。仅在拟用活性主张时增加与之匹配的含量、结构或功能评价。消费者体验测试说明招募范围、知情流程、样本限制、评价工具及停测条件，不将体验结果写成临床效果。

先核实蒙特威及其已明确合作链的承制能力；存在实际缺口时才把历史OEM名单作为条件性补充，不把历史短名单当成已合作工厂。输出委托开发、技术保密、配方与商标权属、打样变更、质量放行、退货召回的责任建议，合同权限仍以实际文件为准。

## 五、市场、竞品与推广方案的具体要求

### 1. 重新核验真正可比的竞品

将原料竞品、同类成品、满足同一需求的替代品分开。优先从现有竞品表选择影响决策的代表SKU深核，不为凑数量引入软文排行。记录国家／地区、渠道、产品类别、准确SKU和口味、规格、标签、实际可得价格及条件、抓取日期和原始链接。缺少资料的竞品明确不可比。

「原料投料占比」「原料蛋白含量」「成品总蛋白」「成品乳清贡献」分栏。混合蛋白产品没有可核配方及原料指标时，不估算其乳清贡献；不得按配料表顺位倒推出比例。不能把全营养食品与单一蛋白补充品的蛋白浓度差写成优劣排名。历史表格所有影响定价的公式须重新核算。

消费趋势研究可提出假设，但2022年消费样本、美国调查、媒体软文、竞品宣称不能证明2026年本项目客群和支付意愿。结合实际渠道资源设计小规模访谈、样品和价格测试，记录拒绝原因及复购观察；没有执行就写拟议研究。

「内蒙古奶源」与原料加工地、成品生产包装地、注册地址分别填写；奶源地域不能自动延伸为有机、草饲、A2、国产全链条或本品疗效。「Ⅱ型」的本品命名依据未明确前，不作为品类升级、技术优越性或溢价轴。「有专利」不能替代产品实施关系和人体效果；「全国线上招商服务」不能变成全国独家总代。

### 3. 分别设计A、B两条成交路径

A线：行业／技术内容触达 → 有效需求登记 → 应用和规格评估 → 试样安排 → 客户应用反馈 → 供应方正式报价 → 合同及交付 → 验收回款 → 复购。为采购、研发、质量和经营决策者分别提供需要的资料。

B线：渠道与客群筛选 → SKU和合作政策说明 → 样品及经营测算 → 小规模首单 → 培训开售 → 终端净售出与售后 → 补货。签约数、进货额、消费者净购买、库存和补货分别计量；不以压货代替需求。

根据现有账号、团队工时、内容能力、预算、履约与客户资源，比较抖音、视频号、小红书、货架电商、企业微信／合规客户服务入口、行业渠道和线下协同的作用。优先提出少量主渠道组合，说明先后顺序、依赖及退出条件。平台准入、留资、站外引导、食品广告和费用规则逐平台核实；无法读取就保留待核，不承诺可直接导流。

同一企业多联系人统一主体编号，A/B机会分开，同笔交易及服务费不重复记账。客户信息最小化收集，禁止把私有联系人、合同或内部工艺资料送入公开爬虫。

### 4. 输出可直接执行的推广材料与排期

输出A/B资料包目录、各自招商页面结构、需求表字段、初次咨询及常见异议答复、试样／试销SOP、报价字段、合作政策清单、售后与投诉处理流程。对外素材中的未知数必须保留明显占位，不能编造销量、好评、效果或合作客户。

制定首月内容日历，每周覆盖对应目标、对象、证据、主题、形式、渠道、行动入口、责任角色、工时、指标和上线前条件；数量随可用人力调整。至少提供A线技术讲解、B线渠道经营、消费者产品理解三个方向的示范内容，以及A/B说明会结构。未证实的功效、价格和授权不进入可发布文案。

## 六、商业模式与测算要求

分别建立供货方货品账、渠道方经营账、潜势咨询服务账；必要时补一张抵销内部往来的项目合并视图。开发费、原料、加工、包材、打样、中试、检验、损耗、物流、平台、佣金、投放、退货、库存、账期和人力都要说明承担主体；不能把招商货值当潜势收入。

下列公式统一单位并保留缺数状态：

- 每份总蛋白（g）＝每份粉重（g）×成品实物基蛋白质量分数。输入若为g/100g，先除以100。
- 一包装总蛋白（g）＝净含量（g）×同基准成品总蛋白质量分数。
- 每25g总蛋白购买成本＝同一SKU实际可得价格÷一包装总蛋白（g）×25。该25g是比价单位，不是个体食用建议；乳清贡献不明时只算总蛋白成本。
- 干基蛋白换算实物基＝干基蛋白质量分数×（1－对应样品水分质量分数）。仅在检测口径与样品匹配时使用，不能用假设水分生成伪实测值。
- 单位贡献＝净销售收入－与该收入对应的产品成本－尚未计入的变动履约、渠道、售后及获客成本；税、退款、返利与退回可售库存分别处理，避免双扣。
- 盈亏平衡量＝该期间需覆盖的固定成本÷正的单位贡献。单位贡献≤0时无常规销量盈亏平衡解；缺参数时不输出销量承诺。

MOQ、预算、价格或费率缺失时，先做参数表、公式和报价／测试任务。确需演示，单列「示例数据，非实测」，不能与实际经营表混写。敏感性可比较原料、包材、CAC、退款率、成交周期和复购；±20%只能作为标明的压力情景，不是波动预测。

未知团队、预算、库存和客户基础统一登记为缺口，提供最低资源可执行版本及补足条件。不得虚构合作协议、融资、采购订单、人员姓名或获客历史。潜势收费方案明确服务边界、履约验收、客户归属、计费基数、退款调减和回款时点。

## 九、交付与验收

默认先交付可编辑Markdown与必要的测算文件；只有明确需要时生成Word／PDF／PPT。正文用直接的方案语言，详细口径、取证过程、QA日志放附件。给出可做的下一步，不因资料不齐将整套方案写成「待确认」。

提交前按同目录验收情景逐条审查：原料与成品未混淆；旧版本未洗成事实；新增产品开发任务已覆盖；A/B双路径明确；每份量、成本与单位可追溯；预算与权限不虚构；技术测试没有伪结果；渠道实销与压货分开；每个核心建议具备依据、动作、角色、资源、指标及调整条件。报告实际完成的检查及未验证部分，不填虚构评分。

本任务授权内部资料整理、分析、提示词及方案编制和必要本地验证；不包含实际生产变更、采购打款、客户／供应商联系、外发资料、投放、发布、签约、远端上传或账户配置变更。需要这些动作时，先准备具体可审阅结果，再取得对应授权。
