# 蒙特威营销与产品开发

- 01 合作基线与责任
    - 已确认的初步分工
        - 蒙特威负责研发及供应
        - 营销公司负责原料B端与成品市场开发、销售
        - 生产方式由蒙特威按能力组织
    - 股权与投入
        - 团队自行组织并分配营销公司股权
        - 蒙特威不控股，可少量或不持股
        - 首期投入额度沿用60万元
        - 出资主体、性质、到账时间待确认
    - 当前产品状态
        - 尚无通过检验、可供销售的成品
        - 尚无正式成品供货条件
        - 蒙特威正在完善建设
        - 原料批次规格、库存和可售能力仍需核验
    - 旧安排调整
        - 70%／30%股权安排由最新决定替代
        - 营销公司开发及委托生产职责转至蒙特威
        - 旧季度100万元及年度400万元目标待重设
        - 20款五批计划改为候选库与条件立项
    - 原料业务｜建议佣金代理
        - 蒙特威与客户签供货合同、开票、收货款
        - 营销公司负责获客、准入跟进与服务
        - 营销公司按协议确认服务收入和收佣
        - 佣金率、基数、续单与回冲待确认
    - 成品业务｜建议限额经销
        - 营销公司向蒙特威采购合格成品
        - 营销公司向消费者或渠道销售、收款
        - 货权、库存、账期及退货责任待确认
        - 寄售作为备选，按交易实质确定收入
    - 双方接口
        - 营销提交需求、价格接受度和预测依据
        - 蒙特威评估、立项、打样、检测及供货
        - 双方签样并确认规格与包装
        - 营销受理售后，蒙特威牵头技术调查
    - 协议必须约定
        - 真实签约、生产、开票与收款主体
        - 品牌、渠道、配方和素材权属
        - 客户归属、续单佣金及合作退出
        - 供货价格、MOQ、交期与价格调整
        - 研发检测费用、库存损失及召回责任
- 02 客户定位与渠道
    - 原料优先客户
        - 有具体应用和准入需求的食品企业
        - 先验证粉剂及相近营养食品应用
        - 核实品牌方与制造方的原料选择权
        - 其他应用按蒙特威技术数据逐项拓展
    - 原料成交步骤
        - 找研发、质量准入和采购负责人
        - 确认应用、现用料和替换原因
        - 约定试样标准并完成反馈
        - 正式报价、订单、交付与回款
        - 按协议结算营销公司佣金
    - 成品客户｜待验证假设
        - 已有乳清消费习惯的成年人
        - 重视口味和便携的普通成年人
        - 有实际动销能力的健身场所与门店
        - 有明确预算和时间的团购采购方
    - 成品渠道顺序｜建议
        - 先做可回访直营和独立门店试销
        - 再发展垂直达人及小规模直播
        - 团购按明确采购项目推进
        - 真实贡献、回款及补货支持后扩渠道
    - 低成本需求验证｜建议规模
        - 20名消费者、5家渠道、3组团购访谈
        - 记录真实购买、替代品及拒绝原因
        - 亲友、赠样与正常价客户分开
        - 访谈结果不外推为整体市场结论
- 03 营销推广与销售
    - 品牌与产品表达
        - 围绕清楚的信息、使用体验和稳定交付
        - 配料、类别、每份营养须对应定版产品
        - 原料指标不得直接当成品指标
        - 营养声称及适用人群按类别审核
    - 内容生产审核
        - 产品认识、冲调体验、选择比较、客户答疑
        - 内容拟稿与商业事实核对
        - 蒙特威技术质量审核产品表述
        - 营销审核平台与销售要求后发布
        - 变更配方同步更新页面、达人和客服资料
    - 达人合作
        - 筛选受众、内容质量及履约能力
        - 寄样绑定版本、批次、任务与费用
        - 协议明确内容、佣金、退佣和素材权利
        - 合作、活跃、出单及结算分别统计
    - 历史百人目标｜待确认沿用
        - 90天100位有效合作达人为历史目标
        - 历史开发期计入90天，起点须核实
        - 唯一自然人、准入、真实承接及有效存续
        - 不得把上市后90天直接替换历史考核时钟
    - 首购与复购
        - 建议每款首轮30名正常价有效新客
        - 建议两个独立门店做小单试销
        - 按实际使用周期回访并记录真实复购
        - 旧6000元广告上限仅作待确认参考
    - 调整或停止
        - 质量疑点暂停相关批次并追溯
        - CM1不为正时暂停扩大销售和投流
        - CM2为负时缩减付费获客并查原因
        - 预算用尽先复盘再审批
        - 门店库存高或现金不足时暂停扩张
- 04 产品组合与研发
    - 首期｜最多两款试销
        - 日常纯乳清条包
        - 椰乳日常补蛋白
        - 逐款放行，可先上市一款
        - 30g条包及10袋盒装仅为研究起点
    - 下一梯队
        - 训练补充蛋白质配方
        - 蛋白与膳食纤维双补充
        - 根据真实需求及技术条件择一推进
    - 条件储备
        - 成人蛋白钙与维生素D
        - 运动控能部分代餐
        - 先核类别、完整营养设计及目标渠道
    - 20款候选库继续保留
        - 首期及重点六款
            - 日常纯乳清条包
            - 椰乳日常补蛋白
            - 训练补充蛋白质配方
            - 蛋白与膳食纤维双补充
            - 成人蛋白钙与维生素D
            - 运动控能部分代餐
        - 后续粉剂六款
            - 力量训练乳清与肌酸
            - 分离乳清高蛋白条包
            - 复合乳清与乳蛋白配方
            - 谷物乳清早餐营养粉
            - 高纤高钙乳清调制乳粉
            - 活性菌高蛋白调制乳粉
        - 暂缓开发八款
            - 高纤软质蛋白棒
            - 夹心涂层蛋白棒
            - 脆粒复合蛋白棒
            - 燕麦乳清烘焙棒
            - 常温乳清可可蛋白饮
            - 常温高蛋白乳饮
            - 清爽型乳清蛋白粉
            - 水解乳清蛋白配方
    - 技术与市场验证
        - 原料批次COA、实物基蛋白及适用性
        - 口味、冲调、分层、均匀性与包装
        - 配方、类别、许可和标签一致
        - 稳定性、保质期、成品检验与追溯
        - 实际付费接受度及可实现单位贡献
    - 专项边界
        - 纯乳清先核自身类别与许可路径
        - 训练和部分代餐核运动营养要求
        - 钙D核强化范围、含量及稳定性
        - 抹茶保留为风味小试，参数待验证
        - WPI894／895及水解研究不代表已到货或已投产
    - 研发交付物
        - 需求评审、配方版本及原料档案
        - 小试中试记录、签样和规格书
        - 检测、稳定性和包装验证资料
        - 标签、允许表述及放行资料
        - 正式供货价、MOQ、交期及变更机制
    - 研发经济性与停止条件
        - 供货成本上限由净收入减费用及目标贡献推导
        - 客户需求、技术质量及成本共同验收
        - 配方比例、指标和周期由蒙特威评审
        - 类别不适用或商业条件不成立时暂停
- 05 研发供应与质量交付
    - 前期确认
        - 营销提交客户需求与价格边界
        - 蒙特威评估立项、费用及排期
        - 技术测试与市场体验分别评价
        - 双方确认样品、规格和包装
    - 采购批准
        - 营销负责人和财务按授权审批
        - 核合同、签样、MOQ及付款条件
        - 核交期、库存消化和13周现金
        - 通过后形成可执行生产采购订单
    - 技术放行
        - 蒙特威及生产方依法组织
        - 核实际商业批次检验及生产记录
        - 留样、追溯及不合格品处理
        - 未通过则隔离、改进或停止
    - 商业开售批准
        - 营销负责人决定，质量和财务复核
        - 到货批次、经营资质和品牌授权齐全
        - 价格贡献、库存、页面和售后已准备
        - 按具体产品记录开售日期
    - 补货与复盘
        - 每周核需求、样品、供货和订单
        - 每周更新13周现金、应收与库存
        - 每月核双业务贡献及共享费用
        - 按动销、交期、MOQ和现金决定补货
    - 售后与异常
        - 营销统一受理并定位订单及批次
        - 蒙特威牵头技术调查和供应端纠正
        - 物流、普通退货与质量退货分别归因
        - 先采取必要保护措施，再处理内部追偿
- 06 人员资源与经营测算
    - 岗位分阶段到位
        - 经营负责人
        - 原料B端销售
        - 成品渠道销售
        - 电商兼达人运营
        - 内容策划制作
        - 客服与订单履约
        - 主播按实际场次兼职或外包
        - 蒙特威提供研发质量供应接口
    - 六岗六个月桥接情景｜非批准预算
        - 月基本工资合计3.4万元
        - 沿用旧22%用工附加假设
        - 月人员支出4.148万元
        - 六个月人员支出24.888万元
        - 含旧其他参数的准备额41.188万元
        - 60万元扣除后余18.812万元
    - 余额仍须覆盖
        - 原料样品、差旅及业务周转
        - 成品采购及库存资金
        - 主播和新增专业支持费用
        - 另议专项费用与现金储备
        - 按实际到岗月份和正式报价重算
    - 收入与贡献分开
        - 原料成交货值与营销佣金收入分列
        - 成品收入扣折扣、退款和销项税
        - CM1扣采购及非获客变动成本
        - CM2再扣同口径获客费用
        - 两业务贡献合计覆盖公司固定费用
    - 资金管理
        - 原料额度、成品额度、共享费用、储备分别管理
        - 跨业务调拨按授权审批
        - 按真实含税收付款日期滚动预测
        - 原料客户付给蒙特威的货款不作营销现金
        - 新年度利润和资金缺口待正式条件后计算
    - 旧结果仅保留比较
        - 四款旧情景年净利14.93万元
        - 旧60万元外追加20.09万元以保留10万元储备
        - 旧结果不能直接用于新双业务方案
        - 原70%／30%及42万／18万拆分已失去适用基础
    - 测算公式与口径
        - 盈亏平衡销量＝期间固定费用÷正单位贡献
        - CM1为获客前贡献，CM2为获客后贡献
        - 原料代理贡献＝净佣金收入－直接变动费用
        - 最低现金缺口结合批准储备确定追加资金
        - 采购成本与专项研发检测费避免重复计算
- 07 阶段计划与经营验收
    - 三个时间起点
        - C0合作启动日
        - R0具体原料具备商业供货条件之日
        - S0具体成品完成商业开售批准之日
        - 各成品分别起算90天
    - 筹备期｜建议期限
        - C0后3个工作日明确主体、接口和资金
        - 7个工作日形成合作条款及原料资料盘点
        - 10个工作日完成首轮客户需求访谈
        - 15个工作日评审首期产品与岗位现金计划
        - 生产采购与开售分别审批
    - 原料R0后90天
        - 1—30天推进具体试样及准入
        - 31—60天跟进测试、报价和采购程序
        - 61—90天跟踪交付、回款和佣金
        - 客户周期超过90天时过程与成交分别评价
    - 成品S0后90天
        - 1—14天开展限额直营与门店试销
        - 15—30天核购买障碍、贡献和到账
        - 31—60天观察到期复购及补货
        - 61—90天决定继续、调整或停止
    - 扩张门槛
        - 补货须满足真实需求、交期、保质期及现金
        - 扩品须有新增需求、技术路线和正贡献
        - 扩渠道须有动销、回款和服务证据
        - 扩编须有持续任务及新增成本承受能力
    - 统计口径
        - 线索、有效商机、订单分别统计
        - 合作达人与出单达人分别统计
        - 净收入、回款、贡献分别统计
        - 原料补单、消费者复购、门店补货分别统计
        - 复购分母仅纳入达到观察期的客户
- 08 待确认决策与证据
    - 合作与资金
        - 股东名单、比例、治理和审批权限
        - 60万元出资人、性质及到账时间
        - 蒙特威签约、生产及收款主体
        - 品牌、渠道、配方及客户权益
    - 原料业务
        - 实际可供牌号、批次COA和库存
        - 代理方式、佣金及续单结算
        - 正式价格、交期与供货保障
        - 样品、测试、差旅等费用承担
    - 成品业务
        - 研发建设排期及首期产品立项
        - 供货价格、MOQ、账期与交期
        - 库存、退货、临期及质量责任
        - 研发检测、制版及专项费用
    - 经营验收
        - 两业务收入、贡献和回款目标
        - 人员到岗、薪酬及专业支持
        - 百人达人目标是否沿用及原起点
        - 现金底线及跨业务调拨规则
    - 内部复核重点
        - 资料与真实业务状态分开
        - 原料代理与成品经销主体分清
        - 采购审批与开售审批分开
        - 固定费用按实际到岗节奏发生
        - 供货未落定和回款延迟列为重点风险
    - 来源与使用边界〔S01—S07〕
        - S01 旧设立运营方案
        - S02 执行手册
        - S03 经营总览
        - S04 资金测算
        - S05 百人目标研究
        - S06 原料客户验证
        - S07 五款产品研究
