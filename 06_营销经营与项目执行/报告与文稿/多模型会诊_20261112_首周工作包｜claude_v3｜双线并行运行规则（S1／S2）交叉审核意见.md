## 1. 法规或逻辑硬伤

|---|---|---|---|

## 2. S2合规化是否完整

**A-α**
- 存在意义有漏洞。按第六节的合并判据，A-α和S1属同一类别、同一工厂，差异只是配比，**在G1几乎一定会并入S1**。也就是说，S2-A的主推路线一立项就被吸收了，规则里没有承认这一点。
- 漏了：WPI采购审批、A-α与S1原味的“可感知差异”定义，以及同类产品不能在名称上暗示“纯”（“纯”已列入禁用词）。

**A-β**
- 只写了“不推荐”，没有终止条件。乳清蛋白做成固体饮料，正是令120号和46号公告最敏感的“与特殊食品混淆”情形。
- 建议**直接删除A-β**，避免以后有人把它当成后门路线。

**A-γ**
- 漏了：GB 11674零售标签怎么写（乳制品标签加营养标签）、乳制品能否委托生产、原料是否外购（外购就等于分装）。
- 漏了：A-γ与S1同品牌销售时，一个是乳制品、一个是特殊膳食用食品，同样有混淆风险。

**S2-B固体饮料**，漏掉了以下几项：
1. 食品分类归属：14.06还是01.03.02（见硬伤#2）。
2. 冲调倍数口径（#3）。
3. 成品CPP检测方法（#4）。
4. GB 14880第3条原则：不得通过使用营养强化剂夸大其含量或作用、误导消费者。
5. 图像审查：高蛋白固体饮料如果用健身、运动场景，可能暗示“运动营养食品”，构成混淆，需要法规意见。
6. 46号公告完整条款：除警示语以外的名称和暗示性要求，需逐条比对。
7. 固体饮料承制方如果和S1不是同一家，需要第二份委托合同、第二份委托生产报告，以及第二套留样和检测。
8. GB/T 29602新旧版切换期的标签方案。
9. **价值悖论**：CPP不能宣称任何功能，也不能做含量声称，B线的消费者价值只剩“配料事实”。这个问题应该在G0就交给用户判断，不该拖到G2。

## 3. R1–R8和关口、合并终止判据的漏洞

| 规则 | 漏洞 | 补充建议 |
|---|---|---|
| R1／R4 | 没有S1各关口的**基线日期**，“延误”无从衡量。容忍期“待定”，没有默认值。如果执行负责人兼任产品负责人，就是自己裁判自己。 | D3前定下S1关口基线表和容忍期。裁决人和产品负责人必须是两个人。 |
| R2 | 只写了B线。A-γ的许可核验同样是低成本闭环，也应该先做。 | 扩展为“S2各路线第一笔投入只用于书面核验”。 |
| R5 | S1没有对应的包材和原料闸门。S2打样费、CPP样品费、检测费不受控。商标申请应早于公开曝光，不该跟G3绑定。 | 三本账各设闸门。商标费从共用账先列。 |
| R6 | 只管同一页面、同一直播段和礼盒。**同一主品牌加相似命名和视觉**本身就可能构成混淆。平台类目资质也没纳入。 | 增加R6b：S2-B名称中不得出现“乳清蛋白粉”，视觉要明显区隔。首发期全面禁止组合装。 |
| R8 | “S1未过关，A-α同步暂停”过于笼统。比如椰子口味失败，不应该连带A-α。 | 只有失败原因属于共用项（原料、承制方、类别、标签母版）时才联动。 |
| 合并链 | B去掉CPP后并入A-α，A-α再并入S1，S1的SKU会被动增加。 | 规定：B去掉CPP就**终止**。并入S1要用户单独批准。 |
| B@G2 | 用“可感知差异”测CPP不合逻辑：CPP本来就没有感官差异，而且不同类别的产品不能直接对比。 | 改为：合规标签下（不做功能宣称）的支付意愿测试，加地板价模型覆盖测试。测试前必须过安全审核。 |
| 缺失判据 | 没有时间盒，也没有以下终止条件：无合格CPP供应商、无固体饮料承制方、WPI未获批、检测不可行、法规变化。 | 每条一句写入第六节。S2的G1设截止日，由用户拍板。 |
| G0 | S2缺少董事长对并行决定的书面追认。 | 和S1的追认合并办理。 |

## 4. 双线并行新增的待拍板问题

**Q1「不改固体饮料」原则的适用范围是？**
- A（推荐）：只适用于S1椰子款。S2-B允许走固体饮料，但须与S1严格区隔。
- B：适用于整个品牌，S2-B终止。
- C：允许，但S2-B必须用另一品牌。

**Q2 S2-A怎么定位？**
- A（推荐）：A-α并入S1，作为原味的复配或规格变体，同时并行核验A-γ。
- B：只保留A-γ，许可不成立就终止。
- C：终止S2-A，S2只做B。

**Q3 S2-B用什么品牌？**
- A：用主品牌，但用名称和视觉强区隔。
- B：设副品牌。
- C：用独立品牌。

**Q4 是否放行WPI采购（用于A-α或B-F2）？**
- A：放行，只限打样量。
- B：不放行，A-α只用WPC＋辅料。

**Q5 在“不能做任何声称”的前提下，B线是否继续？**
- A（推荐）：继续到G1法规意见出来再决定，期间只花书面核验的钱。
- B：现在冻结。

**Q6 S2资源上限用什么形式？**
- A：工时比例。
- B：S2预算上限，金额待批。
- C：S1延误容忍期，以工作日计，天数由用户定。
- 三项可以多选。

**Q7 首发期能否做组合装或礼盒？**
- A（推荐）：一律禁止。
- B：G4以后，在两者标签分别签审的前提下允许。

**Q8 S2的委托方定谁？**
- A：和S1一致，与09号Q4联动。
- B：S2单独确定。

**Q9 标签版本按哪套？**
- A（推荐）：首批直接按GB 7718／GB 28050—2025。
- B：按旧版，同时做好切换准备。

**Q10 如果冲调倍数取保守口径，怎么办？**
- A：去掉B-F3，保留B-F1和B-F2。
- B：调整标签上的最低加水量。
