# 官网审阅与维护

直接打开「网站/index.html」，或在「网站」目录运行本机静态服务。Windows 和 macOS 的浏览器均可阅读静态页面；本次实际验证环境为本机 Chrome。当前构建使用 noindex 供审阅。正式发布应重新核对域名、canonical、语言对应和索引策略，确认原有联系人的公开授权及各批次附件权限。

- 「网站」为浏览文件。「工程」保留既有基线、双语产品数据、构建器、交互、样式与示意图。「验收」包含截图、浏览器检查结果、走查记录与撤回演练。
- 调整原料介绍、矩阵或字段时编辑「工程/品类内容.json」，分别维护中文与英文。在装有 Python 3 与 Beautiful Soup 4 的环境执行 python3 工程/build.py，再复核两种语言。构建器按当前允许的产品和文件生成页面。
- 如批准 PDF 公开，将原件放在「工程/获准资料」，在品类 documents 中登记 file、zh、en、status；status 为 approved 时随构建导出。撤回时改为 withdrawn，重新构建并以完整目录替换发布包；托管端还需清理旧附件与缓存。公开文件在登记前须核对料号、版本、批次适用性、授权与到期日。当前没有获准发布的批次文件。
- 回退时使用保留的旧发布包。内部研究与完整资料库仍在原项目知识库中，交付给外部时选用「访客审阅包.zip」。
- 分析指标建议依次观察品类详情访问、资料需求选择、换算有效完成、电话入口点击；本版不发送访客数据。真实收件或合格询盘数以接收方记录判定。域名发布后再测真实用户 Core Web Vitals，本机加载耗时只作调试数据。
